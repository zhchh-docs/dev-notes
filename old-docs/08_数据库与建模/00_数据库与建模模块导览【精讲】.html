技术栈详解 · 08_数据库与建模

数据库与建模 · 模块导览

精讲 本模块 10+1 篇 · 建议学习时长 2~3 周

数据库是全栈的"另一半"。本模块主线是 MySQL 三部曲（入门与 SQL → 索引与优化 → 事务与锁），然后是缓存之王 Redis 两部曲，再到扩容（分库分表）与专用引擎（ES/MongoDB），最后是企业级 Oracle 与建模工具。

1这个模块解决什么问题

读完本模块，你应该能：写出跑得快的 SQL 并说清为什么快，设计缓存策略并避开三大经典坑，为业务规模规划存储方案。

  • 给转全栈的你：SQL 人人会写，索引与事务原理决定你写的是"能跑"还是"能扛"。
  • 给面试的你：B+ 树与回表、隔离级别与幻读、缓存穿透/击穿/雪崩、分布式锁，是高频四连。
  • 给架构的你：分库分表与读写分离的时机判断，是业务从 0 到 1 到 N 的存储路线图。
