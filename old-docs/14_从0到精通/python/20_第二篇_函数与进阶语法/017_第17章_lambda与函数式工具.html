17.1 lambda 匿名函数

语法：lambda 参数: 表达式。它返回一个函数对象，函数体只能是单个表达式（表达式的值即返回值）。

# 对比：普通函数 vs lambda
def square(x):
    return x ** 2

square_lambda = lambda x: x ** 2

print(square(5), square_lambda(5))     # 25 25
print(type(square_lambda))             # <class 'function'>

lambda 的三个正当用途：

# ① 作为排序/提取的 key（最常见）
students = [{"name": "张三", "score": 88}, {"name": "李四", "score": 95}]
print(sorted(students, key=lambda s: s["score"])[-1]["name"])     # 李四

# ② 作为短小的回调
pairs = [(1, "one"), (2, "two"), (3, "three")]
print(sorted(pairs, key=lambda p: p[0]))       # [(1, 'one'), (2, 'two'), (3, 'three')]

# ③ 需要表达式的地方（如 GUI/异步回调、defaultdict 工厂）
from collections import defaultdict
tree = defaultdict(lambda: {"count": 0, "children": {}})
tree["a"]["count"] += 1
print(dict(tree))          # {'a': {'count': 1, 'children': {}}}
常见坑① lambda 里不能写语句（没有 if/for/return/raise，也没有赋值——要赋值请用 :=）；② 把复杂 lambda 赋给变量是反模式（PEP 8 明确反对 f = lambda x: ...，此时请用 def，因为它有名字、可写文档、能出现在 traceback 里）；③ 循环里定义 lambda 注意 late binding（第 12 章）。

17.2 map / filter / reduce

nums = [1, 2, 3, 4, 5]

# map：对每个元素应用函数（返回迭代器，惰性）
print(list(map(lambda x: x * 2, nums)))          # [2, 4, 6, 8, 10]
print(list(map(str, nums)))                      # ['1', '2', '3', '4', '5']

# 多个可迭代对象：并行传入，以最短的为准
print(list(map(lambda a, b: a + b, [1, 2, 3], [10, 20, 30])))   # [11, 22, 33]

# filter：保留使函数返回真的元素
print(list(filter(lambda x: x % 2 == 0, nums)))  # [2, 4]
print(list(filter(None, ["a", "", "b", None])))  # ['a', 'b']  None 表示"用真假值过滤"

# reduce：累积归约（需要从 functools 导入）
from functools import reduce
print(reduce(lambda a, b: a * b, nums))          # 120  阶乘
print(reduce(lambda a, b: a + b, nums, 100))     # 115  带初始值
函数等价推导式什么时候用它
map(f, seq)[f(x) for x in seq]f 是已有函数时（如 str、int）更简洁
filter(p, seq)[x for x in seq if p(x)]同上；多数时候推导式更好读
reduce(f, seq)无直接等价归约成单个值；但 sum/max/any 更快更清晰
 
# reduce 的替代：内置函数通常更好
from functools import reduce
nums = [1, 2, 3, 4]

print(reduce(lambda a, b: a + b, nums))    # 10
print(sum(nums))                           # 10   ← 更快、更清晰

print(reduce(lambda a, b: a if a > b else b, nums))
print(max(nums))                           # 4    ← 同样

# 真正适合 reduce 的场景：没有内置对应物的自定义归约
print(reduce(lambda acc, x: acc + [x * 2], nums, []))     # [2, 4, 6, 8]

经验法则：有现成的内置函数（sum/max/min/any/all/join）就用内置的；需要自定义变换时优先推导式；map/filter 只在"直接传已有函数"时更优雅。

17.3 sorted 与 key 的艺术

people = [
    {"name": "张三", "age": 20, "score": 88},
    {"name": "李四", "age": 18, "score": 95},
    {"name": "王五", "age": 20, "score": 95},
]

# 单键排序
print([p["name"] for p in sorted(people, key=lambda p: p["age"])])
# ['李四', '张三', '王五']

# 多键排序：key 返回元组，按元组逐项比较
print([p["name"] for p in sorted(people, key=lambda p: (p["age"], p["score"]))])
# ['李四', '张三', '王五']

# 混合升降序：数值取负即可让某一键降序
print([p["name"] for p in sorted(people, key=lambda p: (p["age"], -p["score"]))])
# ['李四', '王五', '张三']   同龄者分数高的在前

# 字符串键无法取负 → 分两步排（先次要键，再主要键，利用排序稳定性）
words = ["Banana", "apple", "cherry", "Apple"]
print(sorted(words, key=str.lower))                 # 忽略大小写
print(sorted(words, key=lambda w: (w.lower(), w)))  # 忽略大小写，同词时按原样

两个重要细节：

  • key 函数只调用一次：Python 会先对每个元素算一次 key（"装饰-排序-去装饰"），所以 key 里可以放较重的操作；
  • 排序是稳定的：相等元素保持原有相对顺序，因此"多轮排序"能实现复杂排序需求。
# 用稳定性做"先按城市升序、再按年龄降序"
rows = [("北京", 20), ("上海", 18), ("北京", 18), ("上海", 20)]
rows.sort(key=lambda r: r[1], reverse=True)      # 先排次要键：年龄降序
rows.sort(key=lambda r: r[0])                    # 再排主要键：城市升序（稳定，保住上一步顺序）
print(rows)      # [('北京', 20), ('北京', 18), ('上海', 20), ('上海', 18)]

17.4 functools 与 operator

from functools import partial, reduce
from operator import itemgetter, attrgetter, methodcaller, mul

# partial：冻结部分参数，生成新函数（比 lambda 更明确，且可 pickle）
def power(base, exponent):
    return base ** exponent

square = partial(power, exponent=2)
cube = partial(power, exponent=3)
print(square(5), cube(2))            # 25 8

# 实战：固定日志前缀
import logging
log_info = partial(logging.getLogger("app").info, "[api]")
# log_info("请求完成")   → 打印 [api] 请求完成

# itemgetter：按下标/键取值，比 lambda 快且支持多键
people = [{"name": "张三", "age": 20}, {"name": "李四", "age": 18}]
print(sorted(people, key=itemgetter("age"))[0]["name"])          # 李四
print([itemgetter("name", "age")(p) for p in people])            # [('张三', 20), ('李四', 18)]

# attrgetter：按属性取值（对象列表排序神器）
class User:
    def __init__(self, name, age): self.name, self.age = name, age

users = [User("张三", 20), User("李四", 18)]
print([u.name for u in sorted(users, key=attrgetter("age"))])    # ['李四', '张三']

# methodcaller：调用指定方法
print(list(map(methodcaller("upper"), ["a", "b"])))              # ['A', 'B']

# operator 模块把运算符变成函数
print(reduce(mul, [1, 2, 3, 4]))     # 24
工具替代的 lambda优势
itemgetter("k")lambda d: d["k"]更快、支持多键、可复现
attrgetter("x")lambda o: o.x支持 a.b.c 多级
methodcaller("m")lambda o: o.m()可带参数
partial(f, x=1)lambda *a: f(*a, x=1)保留 f.__name__、可序列化

17.5 函数式 vs 推导式

同一需求的四种写法，可读性排序：

nums = [1, 2, 3, 4, 5, 6]

# ① 循环（最啰嗦，但可扩展性最好）
result = []
for n in nums:
    if n % 2 == 0:
        result.append(n ** 2)

# ② 推导式（Python 推荐，多数场景首选）
result = [n ** 2 for n in nums if n % 2 == 0]

# ③ map + filter（函数式风格，需要 lambda 时略绕）
result = list(map(lambda n: n ** 2, filter(lambda n: n % 2 == 0, nums)))

# ④ 已有函数时的 map/filter（此时很优雅）
result = list(map(abs, filter(None, [-1, 0, 2, -3])))      # [1, 2, 3]

取舍建议：

场景推荐写法
变换 + 过滤，逻辑简单列表推导式
只对已有函数做变换/过滤map / filter
链式多步处理、数据量大生成器管道（第 14 章）
需要异常处理、复杂分支普通 for 循环
需要维护累积状态循环 / itertools.accumulate

Python 是多范式语言，但它不鼓励极端函数式：可读性优先，能一眼看懂的写法就是好写法。Guido 甚至一度想把 reduce、lambda 从 Python 3 移除（最终留下了 lambda）。
