1.1 Python 是什么

一句话定义：Python 是一门高级、动态类型、解释执行的通用编程语言，以"可读性优先"为设计哲学。

拆开看这三个定语：

  • 高级：不用管内存地址与指针，变量即用，内存由解释器的垃圾回收机制（引用计数为主 + 分代回收兜底）代劳；
  • 动态类型：变量不声明类型，x = 1 之后 x = "hello" 完全合法。类型检查发生在运行时——第 35 章的类型注解与 mypy 正是给它补上静态检查；
  • 解释执行：源码先被编译成字节码，再由 Python 虚拟机逐条执行，因此能一行一行交互式地跑（REPL）。

设计哲学：一行命令就能看到

1989 年圣诞假期，荷兰人 Guido van Rossum（社区尊称"终身仁慈独裁者"）为了打发时间创造了 Python。这个语言把"多写一点是为了让人读懂"写进了骨子里，浓缩成 19 条格言：在任何装好 Python 的机器上输入：

import this

输出里最值得记住的三条：

  • 优美胜于丑陋，明了胜于晦涩——所以 Python 强制缩进、语法贴近自然语言；
  • 简单胜于复杂——所以解决一个问题通常只有一种显而易见的写法（社区称之为 TOOWTDI）；
  • 可读性很重要——所以 Python 代码读起来几乎像伪代码，这是它成为教学第一语言的原因。

Python 的性格：牺牲一点运行速度，换取写代码、读代码、改代码的速度。绝大多数业务场景里，这笔交易稳赚。

1.2 它能做什么

很多人以为 Python 只是"人工智能的语言"，这个印象至少落后了十年。今天的版图：

领域典型产物关键角色
Web 后端API 服务、内容站点、运营后台FastAPI / Django / Flask（第五篇专题）
数据与 AI数据分析、机器学习、大模型应用pandas / PyTorch / LangChain
自动化脚本批量改名、定时报表、办公自动化标准库 + openpyxl 等
测试与运维自动化测试、CI 脚本、基础设施编排pytest / Ansible
爬虫与采集页面抓取、接口聚合requests / httpx / Scrapy
科学计算仿真、信号处理、生物信息NumPy / SciPy

它的两个短板（诚实告知）

  1. 单线程执行速度慢：纯 Python 循环比 C 慢一到两个数量级。三条出路——把热点交给 NumPy 等 C 扩展、用多进程并行（第六篇）、或直接接受它（多数系统瓶颈在 IO 而非 CPU）；
  2. 移动端与浏览器前端缺席：App 与网页交互仍是 JavaScript 的地盘，Python 基本不参与。

一句话定位：Python 吃下了"数据"与"自动化"两个生态位；人机界面归 JS，极致性能归 C/C++/Rust——而 Python 常常是那层把它们粘起来的胶水。

1.3 版本抉择：为什么是 Python 3

你一定听过"Python 2 和 Python 3 不兼容"。时间线决定了今天的答案：

时间事件对你的意义
2000Python 2.0 发布已成历史，仅在老项目里见到
2008Python 3.0 发布，不向后兼容打破旧代码，社区花了十年迁移
2020-01Python 2 官方停止维护还在教 print 语句的教程，直接换掉
2022 至今3.11 / 3.12 / 3.13 相继发布，每年 10 月一个大版本本书面向 3.10+，涉及版本差异处会标注

选择原则很简单：跟着官方仍在维护的版本走。每个大版本约支持 5 年，写新项目选最新稳定版，维护老项目看团队锁定的版本。

常见坑网上老教程里的 print "hello"（无括号）、xrange、urllib2、raw_input 都是 Python 2 遗物。看到这些写法，说明教程年纪太大了。

1.4 生态：PyPI 与自带电池

Python 的另一个外号是"自带电池（batteries included）"：标准库覆盖文件、网络、并发、压缩、日期、日志、正则……大量脚本零第三方依赖就能写完。第四篇工程化的底气就来自这里。

标准库不够用时去 PyPI（Python Package Index）——全球最大的语言包仓库之一，包含几十万个第三方包，用 pip install 包名 安装（第 31 章专题）。几大件先混个脸熟：

  • requests / httpx：发 HTTP 请求的事实标准；
  • fastapi + uvicorn：现代 Web API 框架（第五篇主角）；
  • sqlalchemy + alembic：数据库 ORM 与迁移（第 44-45 章）；
  • pydantic：数据校验（第 42 章）；
  • pytest：测试框架（第 34 章）；
  • pandas / numpy：数据分析与科学计算两块基石。

语言、解释器实现与发行版：三组概念

概念指什么例子
语言语法定义与标准行为本书记录的对象
解释器实现按标准造出来的"引擎"CPython（官方，本书默认）、PyPy、MicroPython
发行版解释器 + 预装包的打包组合Anaconda（数据科学常用）、python.org 官方版
99% 的场景用官方 CPython 即可。没有特殊理由，不要一上来就装 Anaconda——它自带的包管理会和 pip 体系打架，是新手环境混乱的头号来源（第 30 章展开）。

由此带来两个常见现象：

  • 项目目录里多出 __pycache__ 文件夹——字节码缓存，删掉无妨，会自动重建，应加进 .gitignore；
  • 错误往往发生在运行时而非"编译时"——拼错一个只有某条分支才会走到的变量名，程序跑到那一行才炸。这解释了为什么 Python 世界格外重视测试与类型检查。
