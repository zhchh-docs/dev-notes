40.1 安装：fastapi 与 uvicorn

FastAPI 只是一个"应用框架"，它自己不负责监听端口、跑事件循环——那是 ASGI 服务器 uvicorn 的活。两个都要装。

先按第 30 章建一个虚拟环境并激活，然后装依赖。现代做法是装带"标准依赖集"的版本：

# 在项目目录下，先建并激活虚拟环境（Windows PowerShell）
python -m venv .venv
.venv\Scripts\Activate.ps1

# 方式一：装标准依赖集（含 uvicorn、httpx 等，推荐）
pip install "fastapi[standard]"

# 方式二：只装最小两件套
pip install fastapi uvicorn

# 验证版本（应看到 0.11x 与 2.x）
python -c "import fastapi, pydantic; print(fastapi.__version__, pydantic.VERSION)"
包角色
fastapiWeb 框架：路由、参数解析、校验、文档生成都归它；本身基于 Starlette 与 Pydantic
uvicornASGI 服务器：监听 TCP 端口、跑异步事件循环、把请求交给 FastAPI
pydantic数据校验库（随 fastapi 装上）：第 42 章专题
如果用 pyproject.toml（第 32 章）管理依赖，就把它们写进 dependencies，用 pip install -e . 或 uv pip install 安装，而不是手敲 pip。

40.2 最小应用：三行代码起一个服务

在项目根目录建 main.py，整个文件就这些——这就是一个能对外提供 HTTP 接口的应用。

# main.py
from fastapi import FastAPI

app = FastAPI(title="我的第一个 API")

@app.get("/")
def read_root():
    return {"message": "Hello, FastAPI"}

逐行拆解：

  • app = FastAPI()：创建应用实例——uvicorn 启动时要找的就是它；
  • @app.get("/")：路径操作装饰器。意思是"当有人用 GET 方法请求根路径 / 时，执行下面这个函数"；
  • def read_root()：普通 Python 函数，返回一个 dict。

对照第 39 章：你写的是"业务函数"，FastAPI 替你完成了解析请求报文 → 调用函数 → 把返回值序列化成 JSON → 组装响应报文这一整条链路。

40.3 运行：uvicorn 与 --reload 热重载

启动命令只有一行，但 main:app 这个写法必须解释清楚——它是"模块:变量"的定位语法。

# 在 main.py 所在目录、虚拟环境已激活的前提下：
uvicorn main:app --reload

# 看到类似输出就说明起来了：
# Uvicorn running on http://127.0.0.1:8000 (Press CTRL+C to quit)
# Started reloader process ...
# Application startup complete.
  • main:app：意思是"main.py 模块里的 app 对象"。如果你的应用放在 app/main.py 里、实例叫 app，就写成 app.main:app；
  • --reload：开发模式下加这个，改完代码存盘 uvicorn 自动重启——只在本地开发用，生产环境绝不要加（第 49 章部署会讲）；
  • 默认监听 127.0.0.1:8000，可用 --host 0.0.0.0 --port 8080 改。

启动后用第 39 章的 curl 打一下：

curl http://127.0.0.1:8000/
# {"message":"Hello, FastAPI"}

对应的原始响应报文（curl -v 可见）：

HTTP/1.1 200 OK
content-type: application/json
content-length: 31

{"message":"Hello, FastAPI"}
常见坑启动报 ModuleNotFoundError: No module named 'main'，几乎都是启动目录不对——uvicorn 必须在 main.py 所在目录执行；或者忘了激活虚拟环境，装的 fastapi 不在当前解释器里。

40.4 返回 dict：类型驱动的 JSON 序列化

FastAPI 的灵魂是"类型注解"：你给参数和返回值标类型，它自动完成解析、校验、序列化、文档生成——这是它比 Flask 快十倍上手的根本原因。

from fastapi import FastAPI

app = FastAPI()

@app.get("/hello")
def hello(name: str = "世界"):
    # name 是查询参数；类型 str；不传时默认 "世界"
    return {"greeting": f"你好，{name}"}

@app.get("/items/{item_id}")
def read_item(item_id: int):
    # item_id 标注 int：FastAPI 自动把路径里的字符串转成整数
    return {"item_id": item_id, "squared": item_id * item_id}

试两个请求，体会"类型驱动"：

curl "http://127.0.0.1:8000/hello?name=Doubao"
# {"greeting":"你好，Doubao"}

curl http://127.0.0.1:8000/items/7
# {"item_id":7,"squared":49}

curl http://127.0.0.1:8000/items/abc
# 422 Unprocessable Entity —— 因为 abc 不是整数

注意最后一个：你没写一行校验代码，传 abc 进去 FastAPI 自动返回 422（第 39 章讲过的那个"语义错"状态码），并附带一份人类可读的错误说明。这就是 Pydantic 在背后工作（第 42 章）。

前端写 TS 时类型只在编译期帮忙；FastAPI 的类型注解在运行时真实执行——参数转换、校验、文档全靠它。这就是"类型即接口契约"。

40.5 自动文档：/docs 与 /redoc

FastAPI 启动后自带两套交互式文档，零配置、随代码实时生成——这是它最打动后端新人的功能。

路径页面特点
/docsSwagger UI可在浏览器里直接填参数、点 "Execute" 发请求；后端调试首选
/redocReDoc只读、排版漂亮，适合给前端同事看接口说明
/openapi.jsonOpenAPI 规格上面两个页面都读这份自动生成的 JSON；可导给代码生成工具

打开浏览器访问 http://127.0.0.1:8000/docs，你会看到 /、/hello、/items/{item_id} 三个接口都列在里面，点进去就能直接调。这份文档不是手写的——它是 FastAPI 读你的函数签名和类型注解自动生成的。

想关闭或改路径：FastAPI(docs_url=None, redoc_url="/docs2")。生产环境常把文档下线或加访问控制。

40.6 Hello World 全流程串一遍

把本章所有命令按顺序排好，复制就能跑通你的第一个后端服务。

# 1. 建项目与虚拟环境
mkdir myapi; cd myapi
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install "fastapi[standard]"

# 2. 写 main.py（见下面的 python 代码块）

# 3. 启动
uvicorn main:app --reload
# main.py
from fastapi import FastAPI

app = FastAPI(title="Hello World API")

@app.get("/")
def index():
    return {"message": "服务已启动"}

@app.get("/hello")
def hello(name: str = "世界"):
    return {"greeting": f"你好，{name}"}
# 4. 另开一个终端，用 curl 验证
curl http://127.0.0.1:8000/
curl "http://127.0.0.1:8000/hello?name=Doubao"

# 5. 浏览器打开交互式文档
#    http://127.0.0.1:8000/docs
# curl "http://127.0.0.1:8000/hello?name=Doubao" 的响应：
HTTP/1.1 200 OK
content-type: application/json

{"greeting":"你好，Doubao"}

恭喜——你已经是一个"能写出可访问 HTTP 接口"的 Python 开发者了。后面三章（路由参数、Pydantic、中间件与依赖）都是在这个最小骨架上添砖加瓦。

✓本章小结

要点一句话
安装fastapi 是框架，uvicorn 是 ASGI 服务器，二者缺一不可
最小应用app = FastAPI() + @app.get("/") + return dict，即成一个接口
启动uvicorn main:app --reload；main:app 指向模块里的 app 对象
类型驱动参数类型注解自动完成转换、校验（422）、文档生成
自动文档/docs（Swagger，可调试）与 /redoc（只读）零配置生成
返回值return dict → 自动 JSON、200、application/json
