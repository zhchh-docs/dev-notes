属性Props（Properties）父组件向子组件下行传递的只读数据，通过函数参数接收。见第 4 章

原子类Atomic CSS / Utility ClassesTailwind 等方案中用细小工具类直接组合出样式的写法。见第 9 章

命令式Imperative亲自调用 DOM API 逐步描述"怎么更新"的编程方式。见第 1 章
状态决定视图UI = f(state)给定状态渲染出确定 UI，状态变化触发视图重新计算。见第 1 章

中文术语英文原名一句话解释所在章节
钩子Hook让函数组件使用状态、副作用等 React 内部能力的可复用函数。见第 10 章
副作用Effect渲染之外、需要与外部系统保持同步的逻辑。见第 10 章
清理函数Cleanupeffect setup 返回的拆除逻辑，在依赖变化前与组件卸载时执行。见第 10、11 章

闭包Closure函数捕获其定义时作用域变量的特性，也是 effect 读到陈旧值的根源。见第 10、11 章
函数式更新Functional UpdatesetState 接收 prev 计算 next 的形式，避免读到旧状态。见第 7 章
自定义钩子Custom Hook以 use 开头、在组件间复用状态逻辑的函数。见第 16 章
纯函数Pure Function相同输入必得相同输出、不产生副作用的函数；组件渲染应保持纯净。见第 41 章
严格模式StrictMode开发模式下双重调用渲染与 effect、提前暴露问题的调试模式。见第 19 章
双重调用Double InvocationStrictMode 下故意执行两次组件函数与 effect，用于检测不纯逻辑。见第 19 章
重渲染Re-renderstate、props 或 context 变化后组件函数再次执行以更新 UI。见第 7 章
派生状态Derived State由 props 或其他 state 直接计算得到的值，通常不应复制进 state。见第 10 章
钩子规则Rules of Hooks只在组件顶层调用、只在函数组件或自定义 Hook 中调用。见第 18 章
调用顺序Call OrderHooks 依靠稳定的调用顺序与内部链表一一对应状态。见第 18 章

B.5第五篇 渲染原理（第 38–46 章）

中文术语英文原名一句话解释所在章节
虚拟 DOMVirtual DOM描述页面结构的轻量 JavaScript 对象树，是 diff 的中间层。见第 38 章
差异比较Diff对比新旧两棵树、找出需要改动节点的过程。见第 38 章
纤维节点FiberReact 16+ 支撑可中断渲染的数据结构单元。见第 39 章

调度Scheduling按任务优先级决定执行顺序的机制。见第 40 章
优先级Priority标记更新紧急程度，紧急任务可打断过渡任务。见第 40、45 章
并发渲染Concurrent可中断、可恢复、能让出主线程的 React 渲染模式。见第 45 章
可中断Interruptible渲染过程被更高优先级任务打断后，可稍后继续。见第 39、45 章
不可变更新Immutable Update更新状态时返回新对象或数组，不直接改写原值。见第 44 章
渲染阶段Render Phase协调计算新树、可被中断与重复执行的阶段。见第 42 章
撕裂Tearing同一渲染周期中读取到外部状态不一致快照的问题。见第 22 章
