✓ 本章小结

要点一句话
INSERT永远写列名清单；多值批量比循环快；LAST_INSERT_ID() 拿自增主键
UPDATE先 SELECT 验证 WHERE，再执行；开 sql_safe_updates 兜底
软删除is_deleted 打标记代替物理删；所有查询记得过滤；注意唯一索引陷阱
冲突处理IGNORE 慎用、REPLACE 少用、ON DUPLICATE KEY UPDATE 首选
批量原则大表更新/删除分批按主键切，避免长事务

✎ 本章习题

A 基础向 product 表一次插入 5 条商品；然后用 SET sql_safe_updates = 1 后执行一条不带 WHERE 的 UPDATE，记录报错内容，再恢复 SET sql_safe_updates = 0。
B 进阶给 customer 的 phone 建唯一索引（ALTER TABLE customer ADD UNIQUE KEY uk_phone(phone)），分别用 INSERT IGNORE、REPLACE INTO、ON DUPLICATE KEY UPDATE 插入重复手机号，观察三者的返回信息与表内数据差异（注意 REPLACE 后的自增 ID）。
C 挑战把 customer 表加上 is_deleted 列并软删一行；思考：此时手机号还能再注册吗？动手验证，并给出你的唯一索引改造方案。
