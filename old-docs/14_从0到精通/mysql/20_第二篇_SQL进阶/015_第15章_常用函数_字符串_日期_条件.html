15.1 字符串函数

字符串函数是导出报表、脱敏查询的主力——记住下面这几个就覆盖 80% 场景。

-- CONCAT：拼接（注意：任何一段为 NULL，整段结果为 NULL）
SELECT CONCAT(name, '-', phone) FROM customer;

-- CONCAT_WS：带分隔符的拼接，自动跳过 NULL 段
SELECT CONCAT_WS('-', province, city, district) FROM customer;

-- SUBSTRING：截取（从 1 开始计数）
SELECT SUBSTRING('13800000001', 1, 3) AS head;   -- '138'

-- TRIM：去首尾空格（LTRIM/RTRIM 只去一侧）
SELECT TRIM('  张三  ');                          -- '张三'

-- REPLACE：全文替换
SELECT REPLACE(name, '键盘', 'KeyBoard') FROM product;

-- LEFT / RIGHT：从左/从右取 N 个字符
SELECT LEFT(phone, 3) AS p3, RIGHT(phone, 4) AS p4 FROM customer;

实战：手机号脱敏

-- 138****0001 格式：前 3 + 4 个星 + 后 4
SELECT
  name,
  CONCAT(LEFT(phone, 3), '****', RIGHT(phone, 4)) AS phone_masked
FROM customer
WHERE id = 42;

-- LOCATE：找子串位置（找不到返回 0）
SELECT name FROM product WHERE LOCATE('键盘', name) > 0;
CONCAT 遇 NULL 全 NULL：CONCAT('a', NULL, 'b') 不是 'ab' 而是 NULL！脱敏/拼地址时若任一字段可空，用 CONCAT_WS 或先 COALESCE。

15.2 日期与时间函数

"昨天的订单""近 7 天""按月份分组"——日期函数决定了时间类报表的写法。

-- 当前时间
SELECT NOW(), CURDATE(), CURTIME();

-- 日期加减：INTERVAL 是最通用的写法
SELECT * FROM orders
WHERE created_at >= CURDATE() - INTERVAL 7 DAY;   -- 近 7 天

-- 日期格式化：2026-10-01 → '2026年10月'
SELECT DATE_FORMAT(created_at, '%Y年%m月') FROM orders;

-- DATEDIFF：两个日期相差多少天（只算日期部分）
SELECT DATEDIFF('2026-10-10', '2026-10-01');       -- 9

-- EXTRACT：取年/月/日/时
SELECT EXTRACT(YEAR_MONTH FROM created_at) FROM orders;

-- 按天分组：DATE(列) 把 datetime 截成日期
SELECT DATE(created_at) AS d, COUNT(*)
FROM orders
GROUP BY DATE(created_at);
常用写法用途
CURDATE() - INTERVAL N DAY昨天/近 N 天的日期边界
DATE_FORMAT(d, '%Y-%m')输出 '2026-10' 月份字符串
DATEDIFF(d1, d2)天数差；小时差用 TIMESTAMPDIFF(HOUR, d2, d1)
DATE(created_at)datetime 截成当天 0 点，用于按日分组

15.3 条件函数：IF / CASE / COALESCE

SQL 里的"if-else"：IF 简单分支、CASE 多分支、COALESCE 给 NULL 兜底。

-- IF(条件, 真值, 假值)：三目运算符
SELECT name, IF(stock > 0, '有货', '缺货') AS stock_status FROM product;

-- CASE WHEN：多分支（报表里给订单状态贴中文名）
SELECT
  order_no,
  CASE status
    WHEN 'PAID'    THEN '已支付'
    WHEN 'SHIPPED' THEN '已发货'
    WHEN 'DONE'    THEN '已完成'
    ELSE '其他'
  END AS status_cn
FROM orders;

-- 另一种 CASE 写法（带区间判断）
SELECT
  name,
  CASE
    WHEN amount >= 1000 THEN '大额'
    WHEN amount >= 100  THEN '中额'
    ELSE '小额'
  END AS level
FROM orders;

-- COALESCE：返回第一个非 NULL 值
SELECT name, COALESCE(nickname, name, '匿名用户') FROM customer;

-- NULLIF(值, 比较值)：相等就返回 NULL（常用于防止除零）
SELECT 100 / NULLIF(cnt, 0) FROM stats;   -- cnt=0 时结果为 NULL 而不是报错
前端思维迁移：CASE WHEN 就是 JS 的 switch，IF 就是三目运算符，COALESCE 就是 `??`（空值合并）——语义几乎一一对应。

15.4 数值与类型转换

-- ROUND：四舍五入（第二参数是小数位）
SELECT ROUND(12.3456, 2);             -- 12.35

-- FLOOR / CEIL：向下/向上取整
SELECT FLOOR(12.9), CEIL(12.1);       -- 12 / 13

-- CAST：显式类型转换
SELECT CAST('123' AS UNSIGNED);       -- 字符串转数字
SELECT CAST(20261001 AS DATE);       -- 数字转日期（需符合格式）

-- 防除零：COUNT(列) 本身不会除零，但自定义比率会
SELECT
  order_no,
  ROUND(
    shipped_cnt / NULLIF(total_cnt, 0), 4
  ) AS shipped_rate
FROM order_stats;

15.5 函数包列，索引失效

本章最重要的一条性能纪律：在索引列上套函数，等于把这个列的索引废掉。

-- 反面：created_at 上有索引，但 DATE() 一包 → 全表扫描
SELECT * FROM orders
WHERE DATE(created_at) = '2026-10-01';

-- 正面：把函数挪到"常量侧"，索引正常使用
SELECT * FROM orders
WHERE created_at >= '2026-10-01'
  AND created_at <  '2026-10-02';

-- 同理：phone 上有索引
-- 反面：WHERE LEFT(phone,3) = '138'   → 全扫
-- 正面：WHERE phone LIKE '138%'       → 走前缀索引
改写口诀：把对列的函数运算，换算成对常量的范围条件。这一条在第 23 章 EXPLAIN 实战里还会反复见到。

✓ 本章小结

要点一句话
字符串CONCAT_WS 跳过 NULL；脱敏 = LEFT + '****' + RIGHT
日期INTERVAL 加减、DATE_FORMAT 格式化、DATE() 截日分组
条件IF 三目、CASE WHEN 分支、COALESCE 兜底、NULLIF 防除零
数值ROUND/FLOOR/CEIL；CAST 显式转换
性能纪律索引列上不要包函数，改写为常量范围条件
