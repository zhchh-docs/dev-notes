B.1 索引与查询优化

中文英文一句话释义
聚簇索引Clustered Index按主键组织数据的索引，叶子节点就是数据行
二级索引Secondary Index非主键索引，叶子存主键值，需回表
回表Bookmark Lookup二级索引查到主键后再去聚簇索引取整行
覆盖索引Covering Index索引包含查询所需全部列，免回表
联合索引Composite Index多列组成的索引，遵循最左前缀
最左前缀Leftmost Prefix联合索引从最左列开始匹配才生效
基数Cardinality索引列不同值的数量，越高越有区分度
执行计划Execution PlanEXPLAIN 输出的查询执行路径
全表扫描Full Table Scantype=ALL，逐行扫描，需避免
慢查询日志Slow Query Log记录超过 long_query_time 的 SQL
查询优化器Optimizer自动选择索引与连接顺序的内部组件
文件排序Filesort无法用索引排序时的额外排序操作

B.2 事务与隔离级别

中文英文一句话释义
事务Transaction一组原子操作，要么全成功要么全回滚
ACIDACID原子性/一致性/隔离性/持久性四特性
隔离级别Isolation LevelRU/RC/RR/Serializable，控制并发可见性
读未提交Read UncommittedRU，能读到未提交数据，脏读
读提交Read CommittedRC，只读到已提交数据
可重复读Repeatable ReadRR，InnoDB 默认，事务内多次读一致
脏读Dirty Read读到别的事务未提交的数据
不可重复读Non-repeatable Read同一事务内两次读同一行结果不同
幻读Phantom Read同一查询两次返回行数不同
MVCCMulti-Version Concurrency Control多版本并发控制，读不阻塞写
回滚日志Undo Log记录旧版本，用于回滚与 MVCC
提交视图Read ViewMVCC 用来判断版本可见性的快照

B.3 锁机制

中文英文一句话释义
行锁Row Lock锁单行，并发度高
表锁Table Lock锁整张表，粒度大并发低
共享锁Shared Lock (S)读锁，多事务可共享
排他锁Exclusive Lock (X)写锁，独占
间隙锁Gap Lock锁索引区间防幻读
临键锁Next-Key Lock行锁+间隙锁，RR 下默认
死锁Deadlock两事务互相等对方释放锁
乐观锁Optimistic Lock用 version 列假设不冲突，提交时校验
悲观锁Pessimistic LockSELECT ... FOR UPDATE 先加锁
锁等待Lock Wait等待行锁释放，受 innodb_lock_wait_timeout 控制

B.4 日志

中文英文一句话释义
重做日志Redo LogWAL，崩溃恢复保证持久性
归档日志Binlog记录所有变更，用于复制与时间点恢复
回滚日志Undo Log记录旧版本，回滚与 MVCC 来源
慢日志Slow Log记录慢查询，优化入口
错误日志Error Log记录启动/运行错误
双 1Double 1innodb_flush_log_at_trx_commit=1 与 sync_binlog=1
二进制日志格式Binlog FormatSTATEMENT/ROW/MIXED，推荐 ROW

B.5 复制与高可用

中文英文一句话释义
主从复制Replication主库 binlog 同步到从库
主库Source / Primary接受写的节点
从库Replica / Secondary同步主库数据的节点
中继日志Relay Log从库中转 binlog 的日志
并行复制Parallel Replication从库多线程回放 binlog 降延迟
高可用High Availability (HA)主库故障自动切换
故障转移Failover主库挂了自动提升从库
半同步Semi-sync主库等至少一个从库确认收到 binlog
读写分离Read-Write Splitting写走主、读走从

B.6 分库分表与分布式

中文英文一句话释义
垂直拆分Vertical Split按业务/字段拆库拆表
水平拆分Horizontal Split按行分片到多个库表
分片键Shard Key决定数据落到哪个分片的列
分库分表Sharding把大库大表拆成多片
分布式事务Distributed Transaction跨库跨服务的事务一致性
最终一致Eventual Consistency短期不一致，异步后收敛
全局唯一 IDGlobal ID分片后主键不能自增，需全局生成

B.7 运维与性能

中文英文一句话释义
缓冲池Buffer PoolInnoDB 缓存数据/索引页的内存区
命中率Hit Rate缓存命中比例，应 > 99%
脏页Dirty Page内存已改未落盘的页
连接池Connection Pool复用数据库连接的池化组件
慢查询Slow Query执行超过阈值的 SQL
QPS/TPSQueries/Transactions Per Second每秒查询/事务数
容量规划Capacity Planning按峰值与冗余估算所需资源
在线 DDLOnline Schema Change不锁业务的在线改表
归档Archiving把历史数据搬离热库
时间点恢复Point-in-Time Recovery (PITR)备份+binlog 重放到指定时刻
