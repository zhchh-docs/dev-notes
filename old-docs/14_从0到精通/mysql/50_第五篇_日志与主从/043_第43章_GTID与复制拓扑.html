43.1 GTID 是什么

GTID（Global Transaction ID）= 一个事务在整个复制体系里的唯一身份证，格式 uuid:seqno。

-- 示例 GTID：3E11FA47-71CA-11E1-9E33-C80AA9429562:23
-- 前半段 server_uuid：实例的唯一标识（自动生成，存在 auto.cnf）
-- 后半段 seqno：这台实例上第 23 个提交的事务

它最大的好处是幂等自动定位：从库只要声明"我已经执行到哪些 GTID 了"，主库就会自动把缺失的事务推过来，不需要人工算文件号和偏移。换主库时这一条省去了最容易出错的一步。

传统复制是"我要从 mysql-bin.000003 的第 1574 字节继续"；GTID 复制是"我已经做到 3E11...:23，把我没有的都发过来"。

图 43-1 GTID 自动定位：从库报"我做到哪"，主库自动补缺口

43.2 开启 GTID

GTID 需要实例级开关，主从两边都要开，并遵守一致性约束。

# my.cnf [mysqld]（主从都配）
gtid_mode = ON
enforce_gtid_consistency = ON
log_bin = mysql-bin
server_id = 1
-- 启动后确认
SHOW VARIABLES LIKE 'gtid_mode';
SHOW VARIABLES LIKE 'enforce_gtid_consistency';

-- 查看本机已执行的 GTID 集合
SHOW MASTER STATUS\G          -- Executed_Gtid_Set 列
SELECT @@global.gtid_executed;
enforce_gtid_consistency=ON 会拒绝不被 GTID 支持的语句（如 CREATE TABLE ... SELECT 老写法、事务内创建临时表）。升级时先开 WARN 模式观察报错，再切 ON。

43.3 基于 GTID 建复制

核心区别：不再填 SOURCE_LOG_FILE/POS，改填 SOURCE_AUTO_POSITION=1。

-- 从库配置：接主库，自动定位位点
CHANGE REPLICATION SOURCE TO
  SOURCE_HOST     = '10.0.0.11',
  SOURCE_PORT     = 3306,
  SOURCE_USER     = 'repl',
  SOURCE_PASSWORD = 'Repl@2026',
  SOURCE_AUTO_POSITION = 1;     -- 关键：让它自动找 GTID 缺口

START REPLICA;

-- 验证
SHOW REPLICA STATUS\G
-- Retrieved_Gtid_Set / Executed_Gtid_Set 是否在推进
换主库场景：主库 A 挂了，从库 B 提升为新主。其余从库只要把 SOURCE_HOST 改成 B、仍用 AUTO_POSITION=1，它们会自动找出"还没从 B 这里同步到的事务"——这就是高可用切换为什么依赖 GTID。

43.4 常见复制拓扑

拓扑结构适用场景
一主多从一个主库挂 N 个从库读多写少，读扩容
级联复制主→从→从从（从库再当别人的主）缓解主库 Dump 线程压力，跨机房
双主两台互为主从高可用切换 + 写就近，需防写冲突
带从的读写分离主写 + 多从读 + 中间件路由第 48 章主题
双主两边都可写极易主键冲突，除非用 auto_increment_increment/offset 错开自增、且业务严格分写，否则别开双写。

43.5 常见坑清单

  • 坑主从 GTID 没对齐就换主：新主上缺的事务不会自动补，数据分叉；
  • 坑在从库手动写数据：会产生本地 GTID，之后再追主库容易冲突；
  • 坑混淆 server_uuid 与 server_id：UUID 自动生成别手改，server_id 要手动唯一；
  • 坑以为开了 GTID 就能跳过错误事务：跳过要用空事务补 GTID（SET GTID_NEXT），不是简单 stop slave。

43.5 GTID 下跳过错误事务

传统位点用 sql_slave_skip_counter 跳一条，GTID 下要注入空事务补位。

-- GTID 模式跳过出错事务：构造一个空事务占用该 GTID
SET GTID_NEXT = 'aaaaaaaa-1111-2222-3333-000000000001:100';
BEGIN; COMMIT;
SET GTID_NEXT = AUTOMATIC;
START REPLICA;
跳过意味着该事务在从库缺失，事后必须补数据并核对，不能跳完就当没事。
