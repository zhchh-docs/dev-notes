65.1 组件库 vs 业务组件

维度业务组件组件库
面向当前项目业务多个项目/团队
耦合可对接本项目接口零业务，只提供能力
API 稳定性可随业务改变更要走版本与迁移说明
交付物源码随工程包 + 文档 + 版本

65.2 入口与导出

// components/index.js：install 让 app.use() 一键注册
import BaseButton from './BaseButton.vue'
import BaseDialog from './BaseDialog.vue'

const components = { BaseButton, BaseDialog }
export default {
  install(app) {
    Object.values(components).forEach(c => app.component(c.name, c))
  }
}
export { BaseButton, BaseDialog }   // 也支持按需 import
// 业务侧使用
import MyUI from '@org/my-ui'
app.use(MyUI)                 // 全量注册
// 或按需
import { BaseButton } from '@org/my-ui'

类型导出：用 TypeScript 写组件时，通过 .d.ts 导出 props 的类型，让使用者有补全。

65.3 版本、文档与测试

  • 语义化版本 semver：主版本.次版本.修订号——改坏了 API 升主版本，加功能升次版本，修 bug 升修订号；
  • changelog：每个版本写清"新增/修复/破坏性变更"，破坏项给迁移指引；
  • 文档站 VitePress：每个组件配一个可交互 demo + 一张 props 说明表；
  • 测试：用 Vitest + Vue Test Utils 对基础组件做渲染与交互测试（第 45 章）。
# 发布前自检与发布（示意）
npm run build        # 打包组件库
npm run test         # 跑组件测试
npm publish          # 发布到 npm（先改 version、确认 peerDependencies）
peerDependencies组件库要把 vue 列为 peerDependencies，而不是 dependencies——否则使用者项目里会被塞进第二个 Vue，导致响应式失效。

65.5 monorepo 组织与 peerDependencies

组件库一旦多包（核心包、主题包、工具包），通常放进 monorepo（pnpm workspace / Turborepo）。包之间本地 link，发布各自独立版本；外部使用方只装需要的包。

my-ui/
├─ packages/
│  ├─ core/        # 组件本体，发布为 @my/ui-core
│  ├─ theme/       # 主题变量，发布为 @my/ui-theme
│  └─ utils/      # 工具函数，发布为 @my/ui-utils
├─ pnpm-workspace.yaml
└─ package.json

peerDependencies 的意义：vue、react 这类"宿主框架"不能打进组件包自己的 bundle——否则使用方项目里会同时存在两份 Vue，响应式、组件实例都对不上。把宿主框架声明为 peerDependencies，既避免重复打包，也把"该装哪个版本"交给使用方决定。

位置放什么为什么
dependencies组件包自己运行时真正用到的三方库（如 dayjs）安装时自动带上
peerDependencies宿主框架（vue/react）避免打进 bundle 造成重复实例
devDependencies构建工具、测试、类型只在开发本包时需要
红线组件包的 dependencies 里出现 "vue"，是 duplicate Vue 的头号来源——看到立即改到 peerDependencies。

组件库发布前要把「宿主框架」从 dependencies 挪到 peerDependencies，否则使用方项目里会出现两份 Vue，响应式与组件实例都对不上。发布清单：构建产物、类型声明、README、CHANGELOG，缺一不可。

// 发布前自检（工程骨架）
// package.json 关键项：
//   "peerDependencies": { "vue": "^3.4.0" },
//   "files": ["dist", "types"],
//   "exports": {".": { "types": "./types/index.d.ts" } }
// 发布：npm publish --access public
// 升级语义化：破坏升主、功能升次、修复修订
duplicate Vue把 vue 打进 dependencies 是重复实例的头号来源——看到立即移到 peerDependencies。
