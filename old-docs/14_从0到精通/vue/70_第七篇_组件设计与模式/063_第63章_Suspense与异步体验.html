63.1 异步组件 + Suspense

异步组件在加载完成前是"空白"。Suspense 让你用一个标签同时声明：加载中显示什么、加载完显示什么。

<script setup>
import { defineAsyncComponent } from 'vue'
const UserProfile = defineAsyncComponent(() => import('./UserProfile.vue'))
</script>

<template>
  <Suspense>
    <!-- 成功后渲染 -->
    <UserProfile />
    <!-- 加载中 fallback -->
    <template #fallback>
      <div class="skeleton">加载中...</div>
    </template>
  </Suspense>
</template>

更关键的是：当 setup 本身是异步的（顶层 await），Suspense 也能接管：

<!-- AsyncPage.vue：setup 里直接 await，Suspense 等它就绪 -->
<script setup>
const data = await fetch('/api/user').then(r => r.json())
</script>

63.2 fallback 与嵌套 Suspense

Suspense 等待树中所有嵌套的异步依赖都就绪才切换到默认内容。嵌套时，内层 Suspense 的 fallback 只替换自己那块，外层保持稳定——避免整页闪烁。

<Suspense>
  <Dashboard />
  <template #fallback><全局骨架 /></template>
</Suspense>

<!-- Dashboard 内部又有局部异步块，单独 fallback，不影响外层 -->
<Suspense>
  <Chart />
  <template #fallback><图表骨架 /></template>
</Suspense>

63.3 错误边界：onErrorCaptured

异步组件加载失败（网络挂了）会抛错。用 onErrorCaptured 在祖先组件捕获，显示错误重试，而不是白屏。

<script setup>
import { ref, onErrorCaptured } from 'vue'
const failed = ref(false)
onErrorCaptured((err) => {
  console.error('异步组件加载失败', err)
  failed.value = true
  return false   // 返回 false 阻止错误继续向上冒泡
})
</script>
<template>
  <p v-if="failed">加载失败，<button @click="location.reload()">点我重试</button></p>
  <Suspense v-else>
    <UserProfile />
    <template #fallback>加载中...</template>
  </Suspense>
</template>

63.4 稳定度说明与体验优化

官方口径Suspense 自 Vue 3 引入，其行为与边界仍在持续演进（官方文档标注为实验性/可能变动）。生产使用前请对照当前版本官方文档确认 API；路由级异步加载更成熟的方案是配合路由懒加载（第 46 章）。
  • 骨架屏：fallback 用骨架而不是转圈，感知更快；
  • 预载：鼠标 hover 路由链接时提前 import()，点开即达；
  • 与 transition 组合：Suspense + transition 可做淡入切换，但要注意出场/入场时机，避免动画错乱。

63.5 常见坑

  • 坑 1把 Suspense 当普通 v-if 用，它只等异步依赖，不等普通 ref。
  • 坑 2异步组件加载失败无任何处理，用户只看到 fallback 一直转。
  • 坑 3嵌套 Suspense 滥用，层级过深导致 fallback 频繁闪烁。

Suspense 让「加载中」与「成功内容」成对声明，但体验细节在预载与超时。鼠标移到导航链接时提前 import 目标异步组件，点开时就秒开；如果异步组件加载过慢，给 fallback 一个超时降级，避免白屏过久。

// hover 预载 + 超时 fallback（工程骨架）
const PageA = defineAsyncComponent(() => import('./PageA.vue'))
function prefetchA() { import('./PageA.vue') }   // 提前拉取
<RouterLink to="/a" @mouseenter="prefetchA">页面 A</RouterLink>
// Suspense fallback 里可加 setTimeout 降级文案
稳定度Suspense API 仍在演进，以当前官方文档为准；生产可用但保持关注变更。

Suspense 的 fallback 别只写「加载中」三个字：给个骨架屏，并加超时降级——异步组件 CDN 加载慢时，用户不会对着白屏猜。hover 预载能让二级页秒开。

// 骨架屏 + hover 预载（工程骨架）
const PageA = defineAsyncComponent(()=>import('./PageA.vue'))
function prefetch(){ import('./PageA.vue') }
