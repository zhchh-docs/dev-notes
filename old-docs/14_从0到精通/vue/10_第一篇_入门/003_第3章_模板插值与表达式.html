3.1 文本插值：双大括号

插值（Interpolation）就是把数据变成文本插进模板。语法是 {{ 表达式 }}，来自"Mustache"（小胡子）语法。

<template>
  <p>你好，{{ name }}</p>
  <p>今天是 {{ weekday }}，共 {{ count }} 条消息</p>
</template>

<script setup>
import { ref } from 'vue'
const name = ref('小明')
const weekday = ref('周一')
const count = ref(3)
</script>

渲染结果：

<p>你好，小明</p>
<p>今天是 周一，共 3 条消息</p>

它是"活"的：count.value++ 之后，页面上的数字会自动变化，不需要任何 DOM 操作。这正是第 1 章说的声明式——你只声明"这里显示 count"。

为什么模板里不用 .value：在 <script setup> 中，ref 会被自动"解包"，模板里直接写变量名即可；但在 JS 代码里必须用 count.value。这个"两套写法"是最常见的新手困惑，第 20 章会从实现层面解释原因。

3.2 插值里能写什么

规则只有一句：只能写"表达式（expression）"，不能写"语句（statement）"。表达式是"能算出一个值"的一段代码。

✅ 可以（表达式）❌ 不可以（语句 / 多语句）
{{ count + 1 }}{{ let a = 1 }}
{{ ok ? '是' : '否' }}{{ if (ok) { return '是' } }}
{{ msg.split('').reverse().join('') }}{{ for (let i of list) {} }}
{{ user.name.toUpperCase() }}{{ a = 1; b = 2 }}
{{ formatDate(createdAt) }}（调用方法）{{ try { ... } catch {} }}
 
<template>
  <!-- 三元表达式做分支：最常见也最推荐 -->
  <span>{{ isVip ? 'VIP 用户' : '普通用户' }}</span>

  <!-- 链式调用：注意别写太长 -->
  <span>{{ (price * discount).toFixed(2) }} 元</span>

  <!-- 调用函数：每次渲染都会重新执行 -->
  <span>{{ formatPhone(phone) }}</span>
</template>

<script setup>
import { ref } from 'vue'
const isVip = ref(true)
const price = ref(99)
const discount = ref(0.8)
const phone = ref('13800138000')

function formatPhone(p) {
  return p.slice(0, 3) + '****' + p.slice(7)
}
</script>

模板里写复杂逻辑会让组件难以维护。当插值超过一行、或需要在多处复用时，就该用计算属性（第 5 章）或方法，而不是把表达式塞进 {{ }}。

3.3 v-text 与 v-html

两者都是"把内容写进元素"，区别在是否解析 HTML 标签。

<template>
  <!-- 三者等价 -->
  <p>{{ raw }}</p>
  <p v-text="raw"></p>
</template>

<script setup>
import { ref } from 'vue'
const raw = ref('<strong>加粗</strong>文本')
</script>

v-text 与 {{ }} 都会转义 HTML，输出的是字面文本：<strong>加粗</strong>文本。想让标签真的生效，用 v-html：

<template>
  <div v-html="html"></div>
</template>

<script setup>
import { ref } from 'vue'
const html = ref('<strong>加粗</strong>文本')
</script>
v-html = XSS 入口。它会把字符串当作真实 HTML 插入，字符串里的 <script>、onerror 属性都会被执行。
  • 永不对用户输入（评论、昵称、上传内容）使用 v-html；
  • 只对受信任来源的富文本使用，且最好在服务端做白名单过滤（如 DOMPurify / sanitize-html）；
  • 能不用就不用：绝大多数"富文本展示"需求，用组件 + 结构化数据渲染更安全。

另外注意：v-html 的内容不受 Vue 模板编译管辖，里面的 {{ }}、指令都不会被处理，样式也不会自动获得 scoped 作用域（需要用 :deep()）。

3.4 v-once：只渲染一次

v-once 让元素/组件只渲染一次，之后数据变化不再更新它。这是纯性能优化手段。

<template>
  <!-- 版权声明、静态说明文字：永不变化，没必要参与后续 diff -->
  <footer v-once>© {{ year }} 某某公司 · {{ company }}</footer>

  <!-- 含大量子节点的静态区块 -->
  <div v-once>{{ longStaticDescription }}</div>
</template>

v-once 的本质：告诉编译器"这棵子树是静态的，跳过它的更新比对"。第八篇讲静态提升时还会遇到类似思路。

3.5 v-pre 与 v-cloak

两个"冷门但有用"的指令：

指令作用典型场景
v-pre跳过该元素的编译，原样输出文档站里展示 {{ }} 语法本身（如本书）
v-cloak编译完成前保留该属性，配合 CSS 隐藏未编译的模板非构建环境（CDN 引入）下防止页面"闪一下大括号"
 
<!-- v-pre：这里的大括号不会被 Vue 解析 -->
<span v-pre>{{ 这里会原样显示 }}</span>

<!-- v-cloak：配合 CSS -->
<div id="app" v-cloak>{{ message }}</div>
[v-cloak] { display: none; }
使用 Vite + SFC 的工程化项目里，模板是预编译好的，不会出现"大括号闪烁"，因此 v-cloak 基本用不上；它主要服务于 CDN 直接引入 Vue 的老式页面。

3.6 插值中的常见类型

不同类型插进去会显示什么？一张表说清：

值显示结果处理建议
null / undefined空字符串（什么都不显示）需要占位符时写 {{ x ?? '暂无' }}
对象[object Object]取具体字段：{{ user.name }}
数组逗号连接的字符串（等价于 toString()）用 v-for 或 {{ list.join('、') }}
true / false显示 true/false业务上通常转中文：{{ ok ? '是' : '否' }}
日期对象一长串默认格式用计算属性 + toLocaleDateString() 格式化
数字 00（注意：0 是"有值"，不是空）判断空值别用 ||，用 ??
 
<template>
  <p>昵称：{{ user.nickname ?? '未设置' }}</p>
  <p>标签：{{ tags.join('、') }}</p>
  <p>余额：{{ balance.toFixed(2) }}</p>
  <p>下单时间：{{ formattedTime }}</p>
</template>

<script setup>
import { ref, computed } from 'vue'
const user = ref({ nickname: null })
const tags = ref(['新客', '活跃'])
const balance = ref(0)
const orderTime = ref(new Date())

const formattedTime = computed(() =>
  orderTime.value.toLocaleString('zh-CN', { hour12: false })
)
</script>

3.7 本章常见坑

  • 坑 1在插值里写语句：{{ if (ok) {...} }} 直接编译报错。用三元 ?: 或计算属性。
  • 坑 2忘记 .value：在 <script setup> 里写 count + 1 得到的是对象字符串拼接。记住：JS 里 .value，模板里不用。
  • 坑 3对用户输入用 v-html：等于给攻击者开了一扇门。坚持"输入转义、输出过滤"。
  • 坑 4用 || 兜底把 0 也兜没了：{{ count || '暂无' }} 在 count = 0 时显示"暂无"。应写 count ?? '暂无'。
  • 坑 5在插值里做重计算：{{ list.filter(...).map(...).sort(...) }} 每次渲染都跑一遍。改用计算属性（第 5 章）缓存结果。

✓ 本章小结

要点一句话
文本插值{{ 表达式 }}；数据变则自动更新，模板内无需 .value
表达式边界只能写能"算出值"的表达式，不能写语句
v-text / v-html前者转义、后者解析 HTML（有 XSS 风险）
v-once只渲染一次，用于静态内容的性能优化
v-pre / v-cloak原样输出 / 防未编译闪烁（CDN 场景）
空值处理null/undefined 渲染为空；兜底用 ?? 而非 ||
