7.1 class 对象语法

对象语法回答一个问题：这个类要不要加？键是类名，值是布尔值（真则加）。

<template>
  <!-- 单个类 -->
  <div :class="{ active: isActive }">面板</div>

  <!-- 多个类 -->
  <div :class="{ active: isActive, 'text-danger': hasError, disabled: isDisabled }">
    状态块
  </div>

  <!-- 值可以是任意表达式 -->
  <div :class="{ 'is-vip': user.level > 3 }">会员</div>
</template>

<script setup>
import { ref } from 'vue'
const isActive = ref(true)
const hasError = ref(false)
const isDisabled = ref(false)
const user = ref({ level: 5 })
</script>

渲染结果（isActive=true, hasError=false）：

<div class="active">状态块</div>

把对象抽到计算属性里（推荐）

<template>
  <div :class="statusClass">{{ statusText }}</div>
</template>

<script setup>
import { ref, computed } from 'vue'
const status = ref('success')   // success | warning | error | pending

const statusClass = computed(() => ({
  'tag-success': status.value === 'success',
  'tag-warning': status.value === 'warning',
  'tag-error':   status.value === 'error',
  'tag-pending': status.value === 'pending',
  'is-loading':  status.value === 'pending'
}))

const statusText = computed(() => ({
  success: '成功', warning: '警告', error: '失败', pending: '处理中'
}[status.value]))
</script>

模板里塞一长串三元判断会迅速失控。超过两个类就用计算属性返回对象，这是团队代码可读性的分水岭。

7.2 class 数组语法

数组语法回答另一个问题：要加哪几个类？（类名本身来自变量或条件）。

<template>
  <!-- 直接列出类名变量 -->
  <div :class="[baseClass, sizeClass]">按钮</div>

  <!-- 数组里嵌对象：既能条件判断又能组合 -->
  <div :class="[baseClass, { active: isActive, error: hasError }]">按钮</div>

  <!-- 数组里写三元 -->
  <div :class="[isActive ? 'active' : 'inactive', 'btn']">按钮</div>
</template>

<script setup>
import { ref } from 'vue'
const baseClass = ref('btn')
const sizeClass = ref('btn-lg')
const isActive = ref(true)
const hasError = ref(false)
</script>
语法适合示例
对象 { a: bool }类名固定，只判断"要不要"{ active: isActive }
数组 [a, b]类名本身就是变量[type, size]
混合 [a, { b: c }]两者都要（最常用）[size, { active }]

7.3 与静态 class 合并

静态 class 与动态 :class 可以同时写，Vue 会合并，不会互相覆盖：

<template>
  <div class="btn base" :class="{ active: isActive }">提交</div>
</template>
<!-- isActive 为真时 -->
<div class="btn base active">提交</div>
Vue3 对 class 做了专门的编译优化：即使值是动态的，静态部分（btn base）也不会参与 diff，属于"静态提升"的一部分（第 68 章）。

7.4 组件上的 class 透传

给子组件写 class，会自动合并到子组件模板的根元素上（这叫"属性透传/ fallthrough attrs"）。

<!-- 父组件 -->
<MyButton class="ml-2" :class="{ 'is-primary': primary }" />

<!-- MyButton.vue（单根） -->
<template>
  <button class="btn"><slot /></button>
</template>
<!-- 渲染结果：父传的 class 合并到子组件的根元素 -->
<button class="btn ml-2 is-primary"></button>
多根组件不会自动透传。子组件模板有多个根元素时，Vue 不知道该挂到哪个上，会告警：Extraneous non-emits event listeners...（class 同理）。解决办法：显式绑定 $attrs——
<template>
  <header v-bind="$attrs">头部</header>
  <main>主体</main>
  <footer>底部</footer>
</template>
<script setup>
defineOptions({ inheritAttrs: false })   // 关掉默认透传，自己指定挂哪
</script>

这也是组件封装的常用技巧：把 class/style 交给使用者控制，组件内部只定义"结构类"。第 56、61 章还会深入。

7.5 style 绑定

<template>
  <!-- 对象语法：CSS 属性名用驼峰或短横线（加引号） -->
  <div :style="{ color: textColor, fontSize: size + 'px' }">文字</div>

  <!-- 直接绑定一个样式对象（可复用、可计算） -->
  <div :style="styleObj">文字</div>

  <!-- 数组语法：合并多个样式对象，后者覆盖前者 -->
  <div :style="[baseStyle, overrideStyle]">文字</div>

  <!-- 多值：数组里给同一属性多个值，浏览器取支持的那个 -->
  <div :style="{ display: ['-webkit-box', '-ms-flexbox', 'flex'] }">弹性布局</div>
</template>

<script setup>
import { ref, reactive, computed } from 'vue'
const textColor = ref('#2d6a3f')
const size = ref(16)
const baseStyle = reactive({ padding: '8px', background: '#f5f5f5' })
const overrideStyle = computed(() => ({ background: textColor.value }))

const styleObj = computed(() => ({
  color: textColor.value,
  fontSize: size.value + 'px',
  fontWeight: size.value > 20 ? 700 : 400
}))
</script>
  • 自动前缀：Vue 会为需要浏览器前缀的属性（如 transform、flex）自动添加前缀；
  • 单位：数字值会自动加 px（如 fontSize: 16 等于 16px），但显式写字符串更清楚；
  • 优先级：数组语法中后面的对象覆盖前面的同名属性。
建议能用 class 解决的就用 class。style 内联样式难以复用、无法用伪类/媒体查询，且优先级最高会压过外部样式表，后期难以覆盖。

7.6 实战：状态标签与主题切换

场景一：状态标签（表格里最常见）

<template>
  <span class="tag" :class="`tag--${status}`">{{ statusMap[status] }}</span>
</template>

<script setup>
import { ref } from 'vue'
const status = ref('pending')
const statusMap = { pending: '待处理', running: '进行中', done: '已完成', failed: '失败' }
</script>

<style scoped>
.tag { padding: 2px 8px; border-radius: 4px; font-size: 12px; }
.tag--pending { background: #fef3c7; color: #b45309; }
.tag--running { background: #dbeafe; color: #1d4ed8; }
.tag--done    { background: #d1fae5; color: #047857; }
.tag--failed  { background: #fee2e2; color: #b91c1c; }
</style>

用模板字符串拼类名比写四个三元判断清爽得多，配合 BEM 命名（tag--xxx）可读性最好。

场景二：主题切换（CSS 变量 + class）

<template>
  <div class="app" :class="{ 'app--dark': isDark }">
    <button @click="isDark = !isDark">{{ isDark ? '切到亮色' : '切到暗色' }}</button>
    <div class="card">内容区</div>
  </div>
</template>

<script setup>
import { ref } from 'vue'
const isDark = ref(false)
</script>

<style>
.app { --bg: #fff; --fg: #1f2e1f; background: var(--bg); color: var(--fg); }
.app--dark { --bg: #1b1b1b; --fg: #eee; }
.card { background: var(--bg); border: 1px solid var(--fg); padding: 16px; }
</style>

主题切换的最佳实践不是"每个元素绑 style"，而是切换一个根 class + 用 CSS 变量驱动整棵树——性能与可维护性都最优。

7.7 本章常见坑

  • 坑 1类名带短横线忘了加引号：{ text-danger: hasError } 是语法错误，必须 { 'text-danger': hasError }。
  • 坑 2多根组件 class 不生效：需要 v-bind="$attrs" + inheritAttrs: false。
  • 坑 3scoped 样式改不到子组件内部：父组件 <style scoped> 只作用于本组件模板；要影响子组件内部元素需 :deep(.child)（第 61 章详讲）。
  • 坑 4style 数组覆盖顺序搞反：后面的覆盖前面的，与 CSS 直觉一致但容易写反。
  • 坑 5把动态样式写进 style 导致无法覆盖：如把颜色写死在内联样式里，主题切换就失效了。优先用 class + CSS 变量。

✓ 本章小结

要点一句话
对象语法{ active: isActive }——判断"要不要这个类"
数组语法[a, b] / [a, { b: c }]——类名来自变量或混合条件
合并规则静态 class 与动态 :class 自动合并，不覆盖
组件透传单根自动合并到根元素；多根需 $attrs 显式绑定
style对象/数组语法；自动前缀；数组后者覆盖前者
最佳实践优先 class（+ CSS 变量做主题），style 只用于真正动态的值
