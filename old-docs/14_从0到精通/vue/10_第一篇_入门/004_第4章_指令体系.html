4.1 指令的语法结构

指令（Directive）是带有 v- 前缀的特殊属性，它的值是一个表达式，Vue 会在数据变化时把这个表达式的结果作用于 DOM。

图 4-1 指令语法拆解

例如 v-on:click.stop="submit"：指令名 on、参数 click（监听哪个事件）、修饰符 stop（阻止冒泡）、值 submit（事件触发时执行的方法）。

两个最强简写：v-bind:src → :src；v-on:click → @click。全书及真实项目默认使用简写。

4.2 v-bind：把数据绑到属性上

插值只能写进元素内容，要绑定属性就得用 v-bind。

<template>
  <!-- 基础用法 -->
  <img :src="avatarUrl" :alt="user.name">
  <a :href="detailUrl">查看详情</a>

  <!-- 布尔属性：值为假时属性直接不渲染 -->
  <button :disabled="isSubmitting">提交</button>

  <!-- 动态属性名（Vue 3.4+ 支持同名简写 :src 等价于 :src="src"） -->
  <a :[attrName]="value">链接</a>

  <!-- 批量绑定对象：一次绑多个属性 -->
  <img v-bind="imgAttrs">
</template>

<script setup>
import { ref, reactive } from 'vue'
const avatarUrl = ref('/avatar.png')
const user = ref({ name: '小明' })
const detailUrl = ref('/detail/1')
const isSubmitting = ref(false)
const attrName = ref('title')
const value = ref('提示文字')
const imgAttrs = reactive({ src: '/a.png', alt: '图片', width: 120 })
</script>
场景写法要点
布尔属性（disabled / checked）值为 false/null/undefined 时属性会被移除；字符串 'false' 会被当成真值
绑定 class / style支持对象与数组语法，详见第 7 章
传参给子组件:user="user"（传表达式）；不加冒号 user="user" 传的是字符串
动态属性名:[attrName]，属性名本身来自变量

最常见的低级错误：<MyComp user="user">——少了冒号，传进去的是字符串 "user" 而不是变量。

4.3 v-on：监听事件

<template>
  <!-- 方法处理器：默认参数就是事件对象 -->
  <button @click="handleClick">点我</button>

  <!-- 内联处理器：可以传自定义参数 -->
  <button @click="remove(item.id)">删除</button>

  <!-- 既要参数又要事件对象：用 $event -->
  <button @click="remove(item.id, $event)">删除</button>

  <!-- 直接写一句简单表达式 -->
  <button @click="count++">+1</button>
</template>

<script setup>
import { ref } from 'vue'
const count = ref(0)
function handleClick(e) {
  console.log('事件对象：', e.target)
}
function remove(id, e) {
  console.log(id, e)
}
</script>
写法拿到的参数适用
@click="fn"(event)只需要事件对象时
@click="fn(1)"(1)需要业务参数（拿不到 event）
@click="fn(1, $event)"(1, event)两者都要

事件修饰符（.stop、.prevent、.once、.self）与按键修饰符在第 9 章展开。

4.4 v-if / v-else：条件渲染

<template>
  <p v-if="score >= 90">优秀</p>
  <p v-else-if="score >= 60">及格</p>
  <p v-else>不及格</p>

  <!-- template 上用 v-if 可以包一组元素 -->
  <template v-if="isLogin">
    <span>{{ user.name }}</span>
    <button @click="logout">退出</button>
  </template>
</template>

v-if 与 v-show 怎么选

维度v-ifv-show
实现条件为假时不渲染 DOM（销毁/创建组件）始终渲染，靠 display:none 切换
切换成本高（重建组件、触发生命周期）低（只改样式）
初始成本低（假时什么都不做）高（无论真假都渲染）
适用切换很少、条件复杂、含重组件频繁切换（如 Tab、下拉 hover）

一句话记忆：切换多用 v-show，条件少变用 v-if。

坑v-if 与 v-for 不要写在同一个元素上。在 Vue3 中 v-if 优先级更高，会导致它拿不到 v-for 的变量而报错。正确做法：外层包一个 <template v-for>，或先用计算属性把列表过滤好（第 8 章详讲）。

4.5 v-for：列表渲染

<template>
  <!-- 遍历数组：(item, index) -->
  <li v-for="(item, index) in list" :key="item.id">
    {{ index + 1 }}. {{ item.name }}
  </li>

  <!-- 遍历对象：(value, key, index) -->
  <li v-for="(value, key, index) in user" :key="key">
    {{ key }}: {{ value }}
  </li>

  <!-- 遍历数字：1..n -->
  <span v-for="n in 5" :key="n">{{ n }}</span>

  <!-- 遍历多个元素用 template -->
  <template v-for="item in list" :key="item.id">
    <dt>{{ item.name }}</dt>
    <dd>{{ item.desc }}</dd>
  </template>
</template>

<script setup>
import { ref } from 'vue'
const list = ref([
  { id: 1, name: '苹果', desc: '红的' },
  { id: 2, name: '香蕉', desc: '黄的' }
])
const user = ref({ name: '小明', age: 18 })
</script>
key 的三大铁律：
  • 必须给 :key（Vue3 中 v-for 无 key 会告警，且无法保证更新正确）；
  • key 必须是稳定且唯一的标识（后端 id），不要直接用数组下标 index；
  • key 不要随机生成（如 Math.random()），那会让每次渲染都重建节点，性能与状态全丢。

用 index 当 key 的经典 bug：删除列表中间一项后，后面项的 index 全部前移，导致表单输入内容"串位"。第 70 章会深入 key 的复用逻辑。

4.6 v-model：双向绑定

v-model 是语法糖：它在表单元素上同时做了"绑定 value"+"监听输入事件并回写数据"两件事。

<template>
  <input v-model="message" placeholder="随便写点什么">
  <p>你输入了：{{ message }}</p>

  <!-- 上面那行等价于 -->
  <input
    :value="message"
    @input="message = $event.target.value"
  >
</template>

<script setup>
import { ref } from 'vue'
const message = ref('')
</script>

不同表单元素的绑定方式

元素绑定的属性 / 事件取值类型
<input type="text">、<textarea>value + input字符串
<input type="checkbox">（单个）checked + change布尔值
多个 checkbox（同 v-model）数组收集 value数组
<input type="radio">收集选中项的 value字符串
<select>value + change单选字符串 / 多选数组
 
<template>
  <input type="checkbox" v-model="agreed"> 同意协议（{{ agreed }}）

  <input type="checkbox" value="vue" v-model="skills"> Vue
  <input type="checkbox" value="react" v-model="skills"> React
  <!-- skills = ['vue', 'react'] -->

  <select v-model="city">
    <option value="bj">北京</option>
    <option value="sh">上海</option>
  </select>
</template>

<script setup>
import { ref } from 'vue'
const agreed = ref(false)
const skills = ref([])
const city = ref('bj')
</script>

三个修饰符

修饰符作用
.lazy把 input 事件改为 change 事件：失焦或回车时才更新，减少高频更新
.number自动把输入转成数字（等价于 Number()），输入框 type="number" 时也建议加
.trim自动去除首尾空白，提交表单前省一次 trim()
组件上的 v-model：<MyInput v-model="msg"> 是另一套机制（modelValue + update:modelValue），第 13 章专门拆解它的本质。

4.7 五条指令速查与常见坑

指令简写一句话
v-bind:attr把表达式的值绑到属性上（含组件 props）
v-on@event监听 DOM 事件或组件自定义事件
v-if—条件渲染，真假决定是否创建 DOM
v-for—列表渲染，必须配稳定唯一的 key
v-model—表单双向绑定（语法糖）
  • 坑 1传参漏冒号：user="user" 传的是字符串。看到子组件收到字符串就查这里。
  • 坑 2v-if 与 v-for 同元素：改成 <template v-for> 包裹或先过滤数据。
  • 坑 3用 index 当 key：删除/插入时状态错乱。
  • 坑 4直接改数组下标或 length：arr[0] = x 在 Vue2 不响应；Vue3 可以，但仍推荐用新数组替换（第 35 章解释原因）。
  • 坑 5v-model 绑了计算属性却没写 setter：报错 "Write operation failed: computed value is readonly"（第 5 章解决）。

✓ 本章小结

要点一句话
指令语法v-名:参数.修饰符="表达式"；: 与 @ 是必备简写
v-bind绑定属性 / props；布尔属性假值不渲染；可 v-bind="对象" 批量
v-onfn 拿 event，fn(a) 只拿参数，$event 手动补
v-if vs v-show前者销毁重建（切换贵），后者 display 切换（初始贵）
v-for数组/对象/数字都可遍历，key 用稳定唯一 id
v-modelvalue + input 的语法糖；.lazy/.number/.trim 三修饰符
