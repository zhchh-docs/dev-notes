◆本章目标

  • 在 Vue3 工程里接入 vue-i18n（createI18n、legacy: false）；
  • 组织多语言 messages 目录，并在组件里用 $t / useI18n；
  • 实现语言切换与 locale 持久化；
  • 掌握插值、复数、日期数字格式化；
  • 与 Element Plus 的 locale 配合，并按需动态加载语言包。
前置要求：组合式 API、main.js 插件注册（第 2、46 章）。

54.1 安装与接入

npm install vue-i18n@9
// src/i18n/index.js
import { createI18n } from 'vue-i18n'
import zhCN from './locales/zh-CN.js'
import enUS from './locales/en-US.js'

const i18n = createI18n({
  legacy: false,          // 组合式模式（配合 <script setup>）
  locale: localStorage.getItem('lang') || 'zh-CN',  // 当前语言
  fallbackLocale: 'zh-CN',                        // 缺词时回退
  messages: {
    'zh-CN': zhCN,
    'en-US': enUS
  }
})

export default i18n
// main.js
import i18n from './i18n'
app.use(i18n)
提醒版本差异：vue-i18n v9+ 才支持 Vue3。在组合式 API（<script setup>）下必须设 legacy: false；不设则默认 legacy 模式，useI18n() 的行为会与预期不同。

54.2 messages 组织

// src/i18n/locales/zh-CN.js
export default {
  common: {
    confirm: '确认',
    cancel: '取消',
    welcome: '你好，{name}'
  },
  nav: {
    home: '首页',
    about: '关于'
  }
}

// src/i18n/locales/en-US.js
export default {
  common: {
    confirm: 'OK',
    cancel: 'Cancel',
    welcome: 'Hello, {name}'
  },
  nav: {
    home: 'Home',
    about: 'About'
  }
}
src/i18n/
├── index.js
└── locales/
    ├── zh-CN.js
    ├── en-US.js
    └── ja-JP.js

语言包按命名空间（common/nav/...）分层，key 用点路径访问；新增语言就是加一个文件，业务代码一行不改。

54.3 组件里使用与切换

<script setup>
import { useI18n } from 'vue-i18n'
const { t, locale } = useI18n()

function switchLang(lang) {
  locale.value = lang                       // 切换当前语言
  localStorage.setItem('lang', lang)        // 持久化
}
</script>

<template>
  <!-- 模板里也可直接用 $t -->
  <h3>{{ t('common.welcome', { name: 'Vue' }) }}</h3>
  <button @click="switchLang('zh-CN')">中文</button>
  <button @click="switchLang('en-US')">English</button>
</template>

图 54-1 切换 locale 同时驱动业务文案与组件库文案（示意）

写法说明
{{ t('nav.home') }}组合式里用 useI18n() 拿到的 t
{{ $t('nav.home') }}模板全局可用的 $t（legacy 模式下更常见）
locale.value = 'en-US'切换语言，界面响应式更新

54.4 插值、复数与格式化

// messages
{
  cart: {
    item: '购物车有 {count} 件商品',
    // 复数：zero/one/other 分支（英文等有复数变化的语言）
    files: 'no files | one file | {count} files'
  }
}
<script setup>
const { t, rt } = useI18n()
t('cart.item', { count: 3 })        // 插值
rt(t('cart.files'), 5)               // rt 运行时解析复数（具体 API 以官方文档为准）
</script>
日期/数字格式化由 i18n 的 datetime/number 格式化能力提供（dt / n），需在 createI18n 里配置对应的格式化规则。具体 API 名随版本演进，以 vue-i18n 官方文档为准。

54.5 持久化、动态加载与 Element Plus 配合

动态加载语言包：语言一多，别全量打进主包。按需 import：

async function loadLang(lang) {
  if (!i18n.global.availableLocales.includes(lang)) {
    const msgs = await import(`./locales/${lang}.js`)   // 路由级懒加载同款
    i18n.global.setLocaleMessage(lang, msgs.default)
  }
  i18n.global.locale.value = lang
  localStorage.setItem('lang', lang)
}

与 Element Plus 配合：组件库自身文案也要跟着切。用 <el-config-provider> 包一层：

<!-- App.vue -->
<template>
  <el-config-provider :locale="elementLocale">
    <router-view />
  </el-config-provider>
</template>

<script setup>
import { computed } from 'vue'
import zhCN from 'element-plus/es/locale/lang/zh-cn'
import enUS from 'element-plus/es/locale/lang/en'
import { useI18n } from 'vue-i18n'
const { locale } = useI18n()
const elementLocale = computed(() => (locale.value === 'en-US' ? enUS : zhCN))
</script>
常见误区：只切了自己业务的语言，Element Plus 组件里的"确定/取消/排序"还是中文。两套语言要同步切，靠 locale 驱动一个 computed 同时改两边。

54.6 本章常见坑

  • 坑 1组合式下忘了 legacy: false：useI18n 行为异常。
  • 坑 2缺词不设 fallbackLocale：漏翻的地方直接显示 key 字符串。
  • 坑 3切语言不持久化：刷新又回到默认语言。
  • 坑 4业务语言切了、组件库语言没切：el-config-provider 没联动。
  • 坑 5所有语言包全量打包：体积膨胀，应动态 import。

✓ 本章小结

要点一句话
接入createI18n + legacy:false + app.use(i18n)
messages按命名空间分文件，新增语言只加文件
使用useI18n 拿 t/locale，模板可用 $t
切换改 locale.value 并写 localStorage 持久化
组件库联动el-config-provider 的 locale 跟随业务 locale
分包语言包多了用动态 import 按需加载

✎ 本章习题

A 基础接入 vue-i18n，准备 zh-CN 与 en-US 两套 common 文案，在导航和一个按钮上用 t() 显示。
B 进阶加一个语言切换下拉：切换 locale 并写入 localStorage，刷新后保持所选语言；再补 fallbackLocale 验证缺词回退。
C 挑战把 Element Plus 的语言也联动切换（el-config-provider），并改成动态 import 加载 en-US 语言包，确认打包后主包不含英文文案。
