◆本章目标

  • 能写出组件 v-model 的等价展开形式（不再把它当魔法）；
  • 掌握默认 modelValue 与具名 v-model 的写法；
  • 会用 Vue 3.4+ 的 defineModel() 大幅简化代码；
  • 能处理自定义修饰符（如 v-model.trim、v-model.upper）；
  • 能为组件实现多个 v-model（如分页的 page + pageSize）。

13.1 原生 v-model 的展开式

第 4 章讲过：在原生表单元素上，v-model 是"绑定 value + 监听 input"的语法糖。

<input v-model="msg">

<!-- 等价于 -->
<input
  :value="msg"
  @input="msg = $event.target.value"
>

关键点：值从哪来（value）、变化往哪去（事件）。组件上没有 value 属性也没有 input 事件，所以 Vue 约定了一套新的名字。

13.2 组件 v-model：modelValue + update:modelValue

<!-- 父组件 -->
<CustomInput v-model="msg" />

<!-- 展开等价 -->
<CustomInput
  :model-value="msg"
  @update:model-value="msg = $event"
/>
<!-- 注意：事件名是 update:modelValue，模板里写 kebab-case 形式也可以 -->

因此子组件只要做到两件事，就"支持 v-model"：

  1. 声明一个名为 modelValue 的 prop；
  2. 在值变化时 emit update:modelValue 事件。
<!-- CustomInput.vue（经典写法） -->
<template>
  <input
    :value="modelValue"
    @input="emit('update:modelValue', $event.target.value)"
  >
</template>

<script setup>
const props = defineProps({ modelValue: { type: String, default: '' } })
const emit = defineEmits(['update:modelValue'])
</script>

用可写计算属性包装（更优雅）

<!-- CustomInput.vue -->
<template>
  <input v-model="value">
</template>

<script setup>
import { computed } from 'vue'
const props = defineProps({ modelValue: { type: String, default: '' } })
const emit = defineEmits(['update:modelValue'])

const value = computed({
  get: () => props.modelValue,
  set: v => emit('update:modelValue', v)
})
</script>

图 13-1 组件 v-model 的数据流

v-model 不违反单向数据流：数据仍归父组件所有，子组件只是用 emit 汇报"用户想改成这个值"。

13.3 具名 v-model：v-model:title

Vue3 允许一个组件绑定多个 v-model，用参数区分：

<!-- 父组件 -->
<UserForm
  v-model:name="form.name"
  v-model:email="form.email"
/>

<!-- 展开 -->
<UserForm
  :name="form.name"
  @update:name="form.name = $event"
  :email="form.email"
  @update:email="form.email = $event"
/>
<!-- UserForm.vue -->
<template>
  <input :value="name" @input="emit('update:name', $event.target.value)">
  <input :value="email" @input="emit('update:email', $event.target.value)">
</template>

<script setup>
defineProps({ name: String, email: String })
const emit = defineEmits(['update:name', 'update:email'])
</script>

典型场景：分页组件（v-model:page + v-model:page-size）、表单组件、抽屉/弹窗（v-model:visible）。

13.4 defineModel（Vue 3.4+）

上面的写法要写 props + emits + computed，样板代码不少。Vue 3.4 起 defineModel() 稳定，一行搞定。

<!-- CustomInput.vue（defineModel 版） -->
<template>
  <input v-model="model">
</template>

<script setup>
// 返回一个 ref，读写它即自动与父组件的 v-model 同步
const model = defineModel()
</script>

它编译后等价于：声明 modelValue prop + 声明 update:modelValue emit + 一个可写计算属性。可以用选项：

<script setup>
// 具名 + 类型 + 默认值
const title = defineModel('title', { type: String, default: '未命名' })

// 必填
const checked = defineModel('checked', { required: true })

// 多个
const page = defineModel('page', { type: Number, default: 1 })
const size = defineModel('pageSize', { type: Number, default: 10 })
</script>

<template>
  <input v-model="title">
  <input v-model.number="page">
</template>
写法代码量适用版本
props + emit（手动）最多所有 Vue3
props + 可写 computed中等所有 Vue3
defineModel()最少Vue 3.4+（3.3 实验）
仍要理解底层：defineModel 只是糖。面试、读源码、改造老代码时，你需要能写出它的展开形式。

13.5 自定义修饰符

原生元素上 Vue 提供 .trim、.number、.lazy。组件上可以自定义修饰符，通过 prop modelModifiers 接收：

<!-- 父组件 -->
<MyInput v-model.upper="text" />

<!-- MyInput.vue -->
<script setup>
const props = defineProps({
  modelValue: String,
  modelModifiers: { default: () => ({}) }   // 命名：model + Modifiers
})
const emit = defineEmits(['update:modelValue'])

function onInput(e) {
  let value = e.target.value
  if (props.modelModifiers.upper) {         // 判断修饰符是否存在
    value = value.toUpperCase()
  }
  emit('update:modelValue', value)
}
</script>

<template>
  <input :value="modelValue" @input="onInput">
</template>

具名 v-model 的修饰符 prop 名为 xxxModifiers（如 v-model:title.upper → titleModifiers）。

用 defineModel 时更简洁：

<script setup>
const [model, modifiers] = defineModel()

function onInput(e) {
  let v = e.target.value
  if (modifiers.upper) v = v.toUpperCase()
  if (modifiers.trim) v = v.trim()
  model.value = v
}
</script>

13.6 多个 v-model 与表单控件族

实战：一个支持两个 v-model 的分页组件。

<!-- Pager.vue -->
<template>
  <div class="pager">
    <button :disabled="page <= 1" @click="page--">上一页</button>
    <span>第 {{ page }} 页</span>
    <button @click="page++">下一页</button>
    <select v-model.number="size">
      <option :value="10">10 条/页</option>
      <option :value="20">20 条/页</option>
      <option :value="50">50 条/页</option>
    </select>
  </div>
</template>

<script setup>
// defineModel 返回的是 ref：直接读写即可，无需 emit
const page = defineModel('page', { type: Number, default: 1 })
const size = defineModel('pageSize', { type: Number, default: 10 })
</script>
<!-- 父组件 -->
<template>
  <Pager v-model:page="query.page" v-model:page-size="query.size" />
</template>

<script setup>
import { reactive, watch } from 'vue'
import Pager from './Pager.vue'

const query = reactive({ page: 1, size: 10 })

watch(() => [query.page, query.size], fetchList, { immediate: true })
async function fetchList() { /* 拉数据 */ }
</script>

组件设计经验：凡是"父组件需要知道它的当前值"的内部状态，都做成 v-model（弹窗的 visible、分页的 page、输入的 value）；纯内部装饰状态（如动画开关）则留在组件内。

13.7 本章常见坑

  • 坑 1事件名写错：update:modelValue 大小写敏感（prop 是 camelCase）；模板里写 @update:model-value 也可，但要保持一致。
  • 坑 2忘了声明 prop：只写了 emit 没写 modelValue prop，父组件传的值进不来（会落到 $attrs）。
  • 坑 3在子组件里直接改 modelValue：props.modelValue = x 告警；用 emit 或计算属性。
  • 坑 4多个 v-model 时混用默认与具名：v-model 与 v-model:title 可以共存（一个默认 + 多个具名），但别写出两个默认 v-model。
  • 坑 5修饰符 prop 默认值：modelModifiers 必须给默认 () => ({})，否则父组件不写修饰符时它是 undefined，读 .upper 会报错。
  • 坑 6Vue 版本不支持 defineModel：3.4 以下需退回 props + emit 写法（或显式开启编译开关）。

要点一句话
本质v-model = :modelValue + @update:modelValue
子组件契约声明 modelValue prop，变化时 emit update:modelValue
具名v-model:title → props title + emit update:title
defineModelVue 3.4+ 一行生成可读写的 ref
修饰符通过 modelModifiers / xxxModifiers prop 接收

数据流仍是单向的：数据归父，子只汇报
