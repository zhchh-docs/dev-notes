B.1 模板与渲染术语

这一组描述界面如何由模板变成 DOM：从虚拟节点树、diff 与 patch，到编译期优化与内置的传送/异步/缓存组件。

它们的关系是：模板经编译器产出带 patchFlag 的 VNode，渲染器对比新旧 VNode 树做 diff，再把结果 patch 到真实 DOM。Teleport、Suspense、KeepAlive 是 Vue 内置的三个"特殊组件"，分别解决挂载位置、异步加载态与实例缓存问题。

中文术语英文一句话释义
虚拟 DOMVirtual DOM用 JS 对象描述界面，diff 后再写真实 DOM
diffdiff比较新旧两棵 VNode 树、找出最小差异的算法
patchpatch把 diff 出的差异应用到真实 DOM 的过程
静态提升hoistStatic编译期把不变节点提到 render 外，只创建一次
动态标记patchFlag编译期标记动态部分的位标记，运行时精准 diff
编译器compiler把模板编译成 render 函数的工具链
blockblock收集动态子节点、跳过静态子树的 diff 容器
片段Fragment多根节点的虚拟节点类型
传送Teleport把节点渲染到 DOM 其他位置（如 body）的内置组件
异步边界Suspense包裹异步组件、提供 fallback 加载态的内置组件
缓存KeepAlive缓存切换走的组件实例、保留状态的内置组件
虚拟列表virtual list只渲染可视区、占位撑高的大列表方案
记法：模板编译做的是"把模板变 render、把静态节点提升、给动态节点打标"，运行时只按 patchFlag 精准 diff。

B.2 响应式与组合式 API

这一组描述数据如何驱动视图：从依赖收集与触发更新的底层机制，到 ref/reactive/computed 等上层 API。

底层是 Proxy 代理：读取时 track 记录依赖，修改时 trigger 通知重跑。上层按数据形态选 API——基本类型用 ref，对象用 reactive，派生值用 computed，跨组件共享用 store。

中文术语英文一句话释义
响应式reactivity数据变化时框架自动更新界面的机制
副作用side effect在响应式计算之外产生的外部影响，如打请求、改 DOM
依赖收集track读取响应式数据时记录当前 effect，便于将来触发更新
触发更新trigger修改响应式数据时，通知所有依赖它的 effect 重新执行
引用ref包装基本类型为响应式引用的 API，脚本内用 .value
响应式对象reactive把对象转为深层响应式代理的 API
计算属性computed带缓存的计算值，依赖不变不重算
侦听watch侦听数据源变化并执行回调的 API
只读readonly创建只读响应式副本，防止意外改状态
取原始值/标记toRaw / markRaw取出原始对象 / 标记对象永不转响应式
解构转引用toRefs把 reactive 属性拆成 ref，解构不丢响应式
浅层响应式shallowRef只跟踪一层的响应式，用于大列表降开销
下一帧nextTick等待 DOM 更新后再执行回调
记法：track 在读取时收集依赖、trigger 在修改时通知重跑，ref 包基本类型、reactive 包对象，computed 带缓存。

B.3 组件与通信

这一组描述组件如何组织与通信：从插槽、单向数据流到依赖注入，以及组合式函数这种复用逻辑的模式。

单向数据流是底线：props 只下传，子组件不直接改，要改就 emit 上抛。插槽解决结构注入，provide/inject 解决跨层传值，composable 把可复用逻辑抽成函数。

中文术语英文一句话释义
组件component可复用的界面单元，含模板/逻辑/样式
插槽slot组件向外暴露、允许父级填充内容的出口
作用域插槽scoped slot把子组件数据传给父级渲染的插槽
单向数据流one-way data flowprops 只从父流向子，子不直接改 props
受控组件controlled component值由父级通过 props 持有、组件只转发
透传属性fallthrough attrs未在 props 声明、自动落到根节点的属性
生命周期lifecycle组件从创建、挂载到卸载的阶段钩子
组合式函数composable以函数形式封装并复用有状态逻辑的模式
依赖注入provide / inject祖先向后代跨层传递数据的机制
自定义事件emit子组件向父组件通知事件的出口
记法：props 下传、emit 上抛、slot 注入结构、provide/inject 跨层——组件通信四件套各管一段。

B.4 路由·状态·工程

这一组描述应用层面的工程概念：路由与守卫、集中状态管理、按需加载与构建优化。

router 把 URL 映射到组件，导航守卫在跳转前后拦截；store 把跨组件共享状态集中管理；懒加载、树摇、SSR 都是为了让首屏更快、包体更小。

中文术语英文一句话释义
状态管理state management跨组件共享状态的集中管理（Pinia）
状态容器storePinia 中管理某块状态的容器
路由routerURL 与组件映射、页面跳转的机制（Vue Router）
导航守卫navigation guard路由跳转前后拦截、决定放行/重定向的函数
懒加载lazy loading路由/组件按需异步加载，减小首屏体积
国际化i18n界面多语言切换（vue-i18n）
树摇tree-shaking打包时剔除未使用代码的优化
构建产物bundle打包后的最终文件
最近最少使用LRU最久未用优先淘汰的缓存策略（KeepAlive max）
服务端渲染SSR在服务端生成 HTML、再交给客户端注水
语义化版本semver版本号 主.次.修订，破坏/功能/修复分级
记法：router 管页面跳转与守卫，store 管跨组件共享状态，懒加载与树摇都是为了让首屏更快。
