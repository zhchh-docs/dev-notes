21.1 Objects：空安全的瑞士军刀

java.util.Objects 提供一组静态工具，专治 NPE：

Objects.equals(a, b);        // 两者都为 null 也安全返回 true
Objects.isNull(x);           // 等价于 x == null
Objects.requireNonNull(x);   // x 为 null 直接抛 NPE，用于参数校验
Objects.toString(x, "空");   // x 为 null 时返回兜底值
永远优先用 Objects.equals 而不是手写 a.equals(b)——后者在 a 为 null 时直接炸。

21.2 Arrays：数组操作

int[] a = {3, 1, 2};
Arrays.sort(a);                       // [1,2,3]
Arrays.binarySearch(a, 2);            // 1（先排序才能二分）
Arrays.fill(a, 0);                    // 全部填 0
Arrays.toString(a);                   // 转可读字符串，便于打印
Arrays.copyOf(a, a.length * 2);       // 扩容拷贝
int[][] m = {{1},{2}};
Arrays.deepToString(m);               // 二维数组专用转串

注意：binarySearch 要求数组已排序；未找到时返回负数（-(插入点)-1）。

21.3 Math / Random

Math.max(3, 5); Math.abs(-2); Math.sqrt(9);
Math.floor(2.9); Math.round(2.5);     // 2.0 / 3
Math.random();                        // [0,1) 随机 double
new Random().nextInt(10);              // [0,10) 整数
new Random().nextInt(5) + 1;          // [1,5]
常见坑频繁 new Random() 且种子时间接近会出重复随机数；需要随机请复用同一个 Random 实例，或用 ThreadLocalRandom。

21.4 UUID 唯一标识

生成全局（极高概率）不重复的 128 位标识，常用于主键、请求追踪：

String id = UUID.randomUUID().toString();  // 如 3a1b...-...-...
// 去掉横杠：id.replace("-", "")

UUID 不依赖中心服务，但字符串较长（36 字符），量大时可考虑雪花算法（Snowflake）等更紧凑方案。
