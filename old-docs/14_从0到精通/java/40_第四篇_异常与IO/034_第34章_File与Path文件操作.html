34.1 File 类的局限

老式 java.io.File 表示路径，但很多方法出错只返回 false 而非异常，且不支持符号链接、批量操作等。虽仍能用于“是否存在/是文件还是目录”的判断，但读写应交给流，复杂操作交给 NIO。

File f = new File("data/a.txt");
f.exists(); f.isFile(); f.isDirectory();
f.createNewFile(); f.mkdirs();

34.2 NIO 的 Path 与 Paths

Path 是 NIO 的“路径 abstraction”，比 File 更现代。Paths.get(...) 构造路径，支持 resolve（拼接）、getParent、getFileName、toAbsolutePath 等组合操作。

Path p = Paths.get("data", "a.txt");   // 跨平台分隔符
Path abs = p.toAbsolutePath();
Path child = p.resolve("sub/b.txt");   // 拼接子路径

34.3 Files 工具类

java.nio.file.Files 提供静态工具：exists、createDirectories、readAllBytes、write、copy、move、delete、walk/list 遍历。

Files.createDirectories(Paths.get("data/out"));
byte[] data = Files.readAllBytes(Paths.get("a.txt"));
Files.write(Paths.get("b.txt"), data);
Files.list(Paths.get("dir")).forEach(System.out::println);
日常文件增删读写，优先用 Files 静态方法，简洁且会抛明确异常。

34.4 相对路径与绝对路径

绝对路径从根开始（如 /usr/a.txt、C:\\a.txt）；相对路径相对当前工作目录（JVM 启动目录）。生产环境尽量用相对路径或配置化根目录，避免硬编码。

常见坑Web/打包后 jar 内资源不能用 File 读取（它不是文件系统路径），要改用 ClassLoader.getResourceAsStream。
