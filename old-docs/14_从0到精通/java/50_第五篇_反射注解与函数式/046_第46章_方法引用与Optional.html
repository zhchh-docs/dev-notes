46.1 方法引用四种形式

当 Lambda 只是"调用一个现成方法"时，可以写成方法引用：类/对象 :: 方法名。

// ① 静态方法引用：类::静态方法
Function<String, Integer> p1 = Integer::parseInt;          // 等价 s -> Integer.parseInt(s)

// ② 实例方法引用（特定对象）：对象::实例方法
String prefix = "ID-";
Function<String, String> p2 = prefix::concat;             // 等价 s -> prefix.concat(s)

// ③ 实例方法引用（任意对象）：类::实例方法
BiFunction<String, String, Boolean> p3 = String::startsWith; // 等价 (s, p) -> s.startsWith(p)
// 编译器自动把第一个参数变成"调用者"——这种"参数当 receiver"的引用最常见

// ④ 构造方法引用：类::new
Supplier<ArrayList<String>> p4 = ArrayList::new;
Function<String, User> p5 = User::new;                     // 匹配 User(String) 构造器
  • 方法引用本身不执行任何逻辑，只是"指向"——执行发生在函数式接口的方法被调用时；
  • 构造引用按参数类型匹配构造器，匹配不到编译错误；
  • Stream 里最常见的组合：map(String::toUpperCase)、map(User::getName)、collect(toCollection(ArrayList::new))。

46.2 Optional 链式防空

NPE 是 Java 的头号异常。Optional（Java 8）用类型把"可能有值"显式化，逼调用方处理空。

// 传统 null 检查地狱
public String getCity(User user) {
    if (user != null) {
        Address addr = user.getAddress();
        if (addr != null) {
            return addr.getCity();     // 可能还是 null……
        }
    }
    return "未知";
}

// Optional 链式
public String getCity(User user) {
    return Optional.ofNullable(user)
            .map(User::getAddress)          // 值存在才继续
            .map(Address::getCity)
            .orElse("未知");                // 链断了给默认值
}
  • 创建：Optional.of(v)（v 非空）、Optional.ofNullable(v)（可能为空，最常用）、Optional.empty()；
  • 取值：get()（空会抛 NoSuchElementException，少用）、orElse / orElseGet / orElseThrow；
  • 判断：isPresent() / ifPresent(consumer)；
  • 过滤与转换：filter(predicate)、map/ flatMap（flatMap 专门拆解 Optional<Optional<T>>）。

46.3 Optional 的正确姿势与过度设计

// 三个"默认值"的求值时机差异——面试常考
Optional<String> o = Optional.empty();

o.orElse(computeDefault());       // computeDefault() 立刻执行，即使 Optional 有值！
o.orElseGet(() -> computeDefault());   // 只有空值时才执行——省开销
o.orElseThrow();                  // 空值抛异常，可定制异常 orElseThrow(() -> new BizException())
  • orElse 的参数是"急切求值"——里面放耗时操作就是隐性浪费；要懒就用 orElseGet；
  • 不该用的场景：① 字段别用 Optional（不可序列化、占内存）；② 方法参数别用 Optional；③ 批量集合返回空 list 比 Optional<List> 好；④ DTO/VO 里别出现；
  • 该用的场景：service/mapper 层返回值——"查无此人"用 Optional 表达比返回 null 更安全；
  • Java 9+：or()（空时返回另一个 Optional）、ifPresentOrElse、stream()（转 0/1 元素流）。
Optional 是"可能没有结果"的返回类型，不是"消灭 null"的银弹——用在返回边界，别用在字段和参数。
