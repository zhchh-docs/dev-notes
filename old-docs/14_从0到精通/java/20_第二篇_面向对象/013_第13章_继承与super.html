13.1 继承：复用与扩展

如果很多类有共同的字段和方法（比如"猫""狗"都会"吃""睡"），把共同点抽到父类，子类用 extends 继承即可，避免重复写代码，又能各自加特色。

class Animal {            // 父类
    String name;
    void eat() { System.out.println(name + " 在吃东西"); }
}
class Cat extends Animal { // 子类：复用 Animal，再扩展
    void meow() { System.out.println(name + " 喵"); }
}
继承的核心价值：父类写一次，所有子类白嫖；子类只写"自己与众不同的部分"。

13.2 extends 与 is-a 关系

Cat extends Animal 读作"猫是一种动物"，即 is-a 关系。这是判断是否该用继承的黄金标准：只有"子类是父类的一种"时才继承，否则请用组合。

  • Java 是单继承：一个类只能 extends 一个父类（但可以实现多个接口，后面讲）；
  • 所有类都隐式继承自 Object，所以任何对象都有 toString()、equals() 等方法。

13.3 super 的三种用法

super 指的是"父类那一份"，常见三种场景：

class Animal {
    Animal(String name) { this.name = name; }
}
class Cat extends Animal {
    Cat(String name) {
        super(name);     // ① 调父类构造器（必须第一行）
    }
    void demo() {
        super.eat();     // ② 调父类方法
        System.out.println(super.name); // ③ 访问父类字段
    }
}
  • 调父类构造器：子类构造器第一行若没写 this(...)，编译器会自动插 super()；父类没有无参构造时你必须显式写 super(参数)；
  • 调父类方法：子类重写了某方法又想用父类的原版；
  • 访问父类字段：父子字段同名时区分。

13.4 方法重写 Override

子类觉得父类某个方法"不够好"，可以同名同参数地重写一份自己的实现。加上 @Override 注解，编译器会帮你检查签名是否真的对得上。

class Animal {
    void sound() { System.out.println("动物叫"); }
}
class Cat extends Animal {
    @Override
    void sound() { System.out.println("喵"); }  // 重写
}

规则：方法名、参数列表必须一致；返回类型要兼容（协变）；访问权限不能比父类更严。@Override 不是必须，但强烈建议——写错签名编译器立刻报错。

13.5 重写 vs 重载

对比重写 Override重载 Overload
发生位置父子类之间同一个类内部
方法签名必须完全相同名同、参数列表不同
返回类型兼容（协变）无要求
本质纵向"替换"父类行为横向"一家人"多种形态

✓ 本章小结

要点一句话
继承extends 复用父类、扩展子类；只在 is-a 时用
super指父类：调构造器（首行）、调方法、访问字段
重写子类同名同参替换父类实现，建议加 @Override
重写≠重载重写看父子、签名相同；重载看同类、参数不同
