11.1 类与对象：图纸与产品

面向对象（OOP）的第一课，就是学会把现实世界"建模"成代码。核心两个词：

  • 类（class）：一张"图纸" / "模具"。它描述一类事物长什么样、能干什么，但本身不是具体的东西。比如「手机设计图」。
  • 对象（object / instance）：用图纸造出来的"具体产品"。比如你手里那台 iPhone。

一张图纸可以造出成千上万个对象；每个对象相互独立，各有自己的状态。这种"先定义模板、再批量生产"的思想，正是 OOP 封装复用的起点。

一句话：类是类型定义，对象是运行时的实体。写代码时你写的是类，跑程序时内存里活的是对象。

11.2 字段（成员变量）与方法

类由两部分构成：

  • 字段 / 成员变量（field）：对象"有什么"——描述状态的名词，比如学生的姓名、年龄。
  • 方法（method）：对象"能干什么"——描述行为的动词，比如学生"学习""考试"。
public class Student {
    // 字段：状态
    String name;
    int age;

    // 方法：行为
    void study() {
        System.out.println(name + " 正在学习，今年 " + age + " 岁");
    }
}

习惯上字段用名词、方法用动词短语；字段一般 private（后面讲封装再展开），这里先用默认权限把模型搭起来。

11.3 用 new 造对象与内存模型

new 是"按下生产按钮"：在堆（heap）内存中开辟一块空间，按类的字段布局放好数据，再调用构造器初始化，最后把这块空间的地址返回给你。

public static void main(String[] args) {
    Student s1 = new Student();   // new：堆里造一个对象，s1 存的是"地址"
    s1.name = "小明";
    s1.age = 18;
    s1.study();                   // 小明 正在学习，今年 18 岁

    Student s2 = new Student();   // 再 new 一个，完全独立
    s2.name = "小红";
    s2.age = 17;
    s2.study();                   // 小红 正在学习，今年 17 岁
}
  • s1、s2 是引用变量，存在栈里，里面装的是"指向堆中对象的地址"；
  • 两个引用指向两块不同的堆内存，所以改 s1.age 不会影响 s2.age；
  • 把 s2 = s1; 只是让两个引用指向同一个对象（别名），并不是复制。
常见坑刚学 OOP 常把"引用"当成"对象本身"。记住：Student s; 只是声明了一个空引用（默认 null），不 new 就调用 s.study() 会抛 NullPointerException。

11.4 this 关键字：指向自己

当方法被某个对象调用时，JVM 偷偷把"这个对象"作为参数传进来，你在方法里用 this 就能拿到它。this 就是"当前对象自己"。

public class Student {
    String name;
    int age;

    void setInfo(String name, int age) {
        // 参数名和字段名撞了，用 this. 区分"我的字段"
        this.name = name;   // 左边是字段，右边是参数
        this.age = age;
    }
}

this 最常见用途：① 区分同名的参数与字段；② 在构造器里调用另一个构造器（this(...)，下章展开）；③ 把"自己"作为参数传给别的方法。

11.5 一个完整小例子

把前面的点串起来：定义类 → new 对象 → 设字段 → 调方法。

public class Demo {
    public static void main(String[] args) {
        Student s = new Student();
        s.setInfo("小明", 18);
        s.study();
    }
}
// 输出：小明 正在学习，今年 18 岁

这就是 OOP 的最小闭环：用类描述"一类事物"，用对象承载"一个个具体实例"，用方法驱动"行为"。
