1.1 三层认知：语言 / JVM / 生态

一句话定位：Java = 一门静态类型的面向对象编程语言 + 一台跨平台的虚拟机（JVM） + 一个庞大的类库与工具生态。

日常说的"Java"其实是三层东西的合称。分层看，很多概念瞬间就清晰了：

层指什么典型代表
语言层语法规则本身：class、if、for、泛型、注解…….java 源文件、javac 编译器
虚拟机层负责执行编译产物的运行时引擎，含内存管理与垃圾回收HotSpot、GraalVM
生态层标准类库 + 海量第三方框架与构建工具JDK 类库、Spring、Maven

为什么这个分法重要？举个例子：Kotlin、Scala 这两门语言语法和 Java 完全不同，但它们编译后同样跑在 JVM 上，可以直接调用 Java 类库——因为它们共享同一层"虚拟机"。反过来，理解了 JVM，你学 Kotlin 也会快很多。

语言决定你"怎么写"，JVM 决定程序"怎么跑"，生态决定你"能站在谁的肩膀上"。三层各学各的，本书前三篇重点在语言层，第七篇深入 JVM 层。

1.2 一次编写，到处运行

1995 年 Java 问世时最惊人的卖点是 Write Once, Run Anywhere。它靠的不是魔法，而是一个中间层设计：

  1. 你写的是 .java 源码（人能读的文本）；
  2. 用 javac 编译成 .class 字节码（一种面向"虚拟 CPU"的指令，与操作系统无关）；
  3. 任何平台只要装了对应版本的 JVM，就能加载并执行同一份字节码。

图 1-1 编译执行模型：javac 一次编译，JVM 各自执行

下面这段代码现在看不懂没关系，第 3 章你会亲手运行它。注意两点：文件名必须叫 Hello.java（与类名一致），以及输出靠类库提供的 System.out 完成——语言与生态协作的最小案例。

public class Hello {
    public static void main(String[] args) {
        System.out.println("Hello, Java!");
    }
}
常见坑很多人把"Java 跨平台"误解为"Java 程序不需要任何安装"。实际上目标机器必须装有对应平台的 JVM（通常随 JRE/JDK 一起分发），跨的是"开发者不用为每个平台重写"这件事。

1.3 Java 的应用版图

打开你手机里的任意一个 App，它背后请求的服务端，很大概率是 Java 写的。Java 的主战场在服务端：

领域典型产物关键角色
企业后端服务电商、银行、政务系统的 API 与微服务Spring / Spring Boot
大数据分布式计算与数据管道Hadoop、Kafka、Flink
Android 开发App（近年 Kotlin 为主，Java 仍可写）Android SDK
中间件消息队列、注册中心、网关Elasticsearch、Nacos、RocketMQ
工具与桌面IDE 本身、构建工具IntelliJ IDEA、Maven、Gradle

Java 的生态位可以概括为：大型、长生命周期、需要稳定维护的服务端系统。这也是为什么它长期占据企业开发语言榜首。

本书的终点（第九至十二篇）正是这条主流路线：Spring Boot + 数据库 + 缓存 + 消息队列的完整后端。前面所有语法，都是在为那一段铺路。

1.4 版本与 LTS：该学哪个

Java 每半年发一个新版本，但不是每个版本都值得追。重要概念是 LTS（Long-Term Support，长期支持版）：

版本类型对学习者的意义
Java 8LTS（2014）老系统存量巨大，面试常问；Lambda 从这版引入
Java 11LTS（2018）模块化落地后的第一个 LTS
Java 17LTS（2021）推荐学习版本：record、switch 增强等现代语法齐备
Java 21LTS（2023）虚拟线程（第六篇会提）；新项目常用
非 LTS 版本过渡版尝鲜用，不必专门学
本书约定：所有示例以 Java 17 为基线，个别新特性（如虚拟线程）会标注最低版本。用 Java 8 的读者在第 45、19、30 章会遇到少量差异，正文均有提示。

怎么查自己的版本？打开终端输入：

java -version
# 输出示例：openjdk version "17.0.10" 2024-01-16

1.5 与其他语言的坐标

用一张表给 Java 定位，方便有其他语言背景的读者迁移、零基础读者建立坐标系：

语言类型系统运行方式典型场景
C静态、手动管内存编译为机器码操作系统、嵌入式
Python动态解释执行脚本、AI、数据
JavaScript动态解释 + JIT网页、Node 服务
Java静态、自动 GC编译为字节码 + JIT企业后端、大数据
Go静态、自动 GC编译为机器码云原生、网络服务
  • 静态类型意味着每个变量声明时必须写明类型，编译期就能查出大量错误——初学觉得啰嗦，项目大了就知道香；
  • 自动 GC意味着你不用像 C 那样手动 free 内存，JVM 替你回收不再使用的对象；
  • JIT（即时编译）让 Java 在"解释执行"的灵活与"机器码"的性能之间取得平衡——热点代码会被编译成本地机器码。
