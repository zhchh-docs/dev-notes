3.1 main 方法逐词拆解

public class Hello {
    public static void main(String[] args) {
        System.out.println("Hello, Java!");
    }
}

这是 Java 程序的"标准入口"。JVM 启动时就是来找这个签名的 main 方法，从它的第一行开始执行。逐词拆开：

部分含义现在需要懂多少
public class Hello声明一个公开类，名为 Hello。Java 代码必须写在类里类是代码的容器（第二篇详讲）
public（方法前）对外可见——JVM 要能从外部调用它访问控制，第 12 章详讲
static属于类本身，不需要先创建对象就能调用第 11 章详讲
void方法不返回任何值第 7 章详讲
String[] args命令行参数数组，运行时传进来的字符串本章 3.2 会用一次
main 的签名是 JVM 与你之间的"接头暗号"，一个词都不能错。写错则运行时报"在类 Hello 中找不到 main 方法"。
常见坑一个源文件可以有多个类，但 public 类只能有一个，且文件名必须与 public 类名完全一致（含大小写）：Hello.java 里是 public class Hello。

3.2 命令行编译与运行全流程

哪怕你日常用 IDEA，也请完整走一遍下面的流程——它让你看到 IDE 帮你隐藏了什么。新建目录写入 Hello.java，然后：

# 1. 编译：生成 Hello.class（字节码）
javac Hello.java

# 2. 运行：把类名（不是文件名！）交给 JVM
java Hello
# 输出：Hello, Java!

# 3. 带参数运行
java Hello 张三 18
# args[0]="张三"，args[1]="18"

接收参数的例子——把 main 改成：

public class Hello {
    public static void main(String[] args) {
        System.out.println("收到 " + args.length + " 个参数");
        if (args.length > 0) {
            System.out.println("第一个参数是：" + args[0]);
        }
    }
}
  • javac Hello.java 必须带扩展名（它是编译器，吃源文件）；
  • java Hello 必须不带扩展名（它是 JVM，找的是类）；
  • Java 11 起单个文件可一步跑：java Hello.java（内部隐式编译，适合学习期）。
常见坑运行报 ClassNotFoundException，多半是：在错误目录执行、类名大小写写错，或忘了先编译。JVM 找的是"当前目录下的 Hello.class"。

3.3 IDEA 里发生了什么

在 IDEA 里点一下绿色三角，背后发生的是与命令行完全等价的动作：

  1. 调用 javac，把 src 下改动过的源码编译到 out/production 目录；
  2. 调用 java，把编译产物交给 JVM 运行；
  3. 把控制台输出重定向到 Run 窗口。

两个实用推论：改了代码必须重新构建（IDEA 默认自动做；偶尔构建缓存出问题，菜单 Build → Rebuild Project 强制重来）；IDEA 报错和命令行报错是同一套，学会读一个就都会了。

调试是 IDEA 相比命令行最大的增值：在代码行左侧单击打断点，用"虫子"图标启动 Debug，程序停在断点处可逐行执行、查看变量。现在先试一下，第六篇排障时它是主力工具。

3.4 三种注释与代码规范

// 1. 单行注释：说明下一行在干什么
int price = 99; // 行尾注释也可以

/*
 * 2. 多行注释：解释一段逻辑
 * 注意多行注释不能嵌套
 */

/**
 * 3. 文档注释：会被 javadoc 工具提取成 API 文档
 * @param args 命令行参数
 */
public static void main(String[] args) { }
  • 注释是写给未来的人看的——多半是你自己。解释"为什么这么写"，而不是复述代码；
  • 命名惯例现在就养成：类名大驼峰（HelloWorld）、方法与变量小驼峰（getUserName）、常量全大写下划线（MAX_VALUE）；
  • 缩进用 4 空格，大括号风格跟团队规范走，保持一致即可。

3.5 初学者编译错误大全

编译器报错信息是帮你定位问题的，不是敌人。五类高频错误：

报错（节选）原因修复
class Hello is public, should be declared in a file named Hello.java文件名与 public 类名不一致重命名文件
';' expected少了分号看报错指向的行号
cannot find symbol变量/类名拼错或未声明检查拼写、大小写
reached end of file while parsing大括号不配对从文件尾往回找漏掉的 }
bad operand types类型不匹配（如字符串减数字）下一章学完类型就懂

读报错三步法：① 看第一行错误类型 ② 看行号 ③ 只修第一个错再编译——一个错可能引发一串连锁报错。

✓ 本章小结

要点一句话
程序入口JVM 按固定签名找 main：public static void main(String[] args)
编译运行javac 带扩展名，java 不带；运行的是类名
IDE 本质自动调 javac/java + 输出重定向 + 调试增值
注释三种// 单行、/* */ 多行、/** */ 文档
读报错错误类型 → 行号 → 修第一个再编译
