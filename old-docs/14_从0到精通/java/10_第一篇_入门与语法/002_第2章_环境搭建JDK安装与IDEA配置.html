2.1 分清 JDK / JRE / JVM，并选一个发行版

三者是包含关系：JDK ⊃ JRE ⊃ JVM。

缩写全称与含义给谁用
JVMJava Virtual Machine：执行字节码的虚拟机所有人（隐含）
JREJava Runtime Environment：JVM + 核心类库，只能"跑"不能"编"只运行程序的用户
JDKJava Development Kit：JRE + 编译器 javac + 调试诊断工具开发者（你）
常见坑只装了"Java 运行环境"就想写代码，运行 javac 会报"不是内部或外部命令"。写 Java 必须装 JDK。

下载哪个 JDK

Java 11 起官方开源，出现多个"发行版"——同一份标准，不同厂商打包：

发行版说明适合
Oracle JDK官方出品，商用需注意许可条款需要官方支持的企业
OpenJDK开源参考实现，各发行版的源头通用
Temurin（Adoptium）Eclipse 维护的开源发行版，口碑好推荐初学者
国内镜像版清华 / 阿里镜像站，下载快网络受限时
版本选 17（LTS）。注意操作系统与架构：Windows 选 x64；macOS 若是 M 系列芯片选 aarch64 版。

2.2 安装与环境变量

Windows

  1. 运行 .msi 安装包，安装路径不要含中文和空格，例如 C:\Java\jdk-17；
  2. 打开"系统环境变量"，新建 JAVA_HOME = C:\Java\jdk-17；
  3. 编辑 Path，新增 %JAVA_HOME%\bin，并移到列表顶部（防止旧 Java 残留抢先）；
  4. 一路确定后重新打开终端——老终端不会读到新变量。

macOS / Linux

macOS 用 Homebrew：brew install --cask temurin@17；Linux 用包管理器安装或解压 tar 包后配置 PATH。多数安装方式会自动注册路径，无需手动设置。

# macOS/Linux 检查与手动配置（如需）
echo $JAVA_HOME
export JAVA_HOME=/usr/lib/jvm/temurin-17-jdk-amd64
export PATH=$JAVA_HOME/bin:$PATH

环境变量的作用只有一个：让终端在任何目录都能找到 java 和 javac 命令。理解这一点，配置出错时你就知道该查哪里。

2.3 验证安装

java -version
# openjdk version "17.0.10" 2024-01-16

javac -version
# javac 17.0.10

echo %JAVA_HOME%      # Windows cmd
echo $JAVA_HOME       # macOS/Linux

三条都要有正常输出。逐个排查思路：

  • java 有输出而 javac 没有 → 装成了 JRE，换装 JDK；
  • 提示"不是内部或外部命令" → PATH 没配对，检查条目拼写与是否在列；
  • 版本号不对（期望 17 却输出 1.8）→ PATH 里旧 Java 排在前面，把新条目上移。

2.4 IDEA 安装与新建项目

IntelliJ IDEA 是主流 Java IDE。Community 社区版免费，前十二篇完全够用；Ultimate 的框架增强到 Spring 阶段再考虑。

  1. 新建项目：New Project → Java，JDK 下拉框选中刚装的 17；
  2. Build system 先选 IntelliJ（最简单）；Maven 到第十一篇再讲；
  3. 在 src 目录右键 New → Java Class，命名 Hello；
  4. 类体内输入 main 按 Tab，IDEA 自动生成主方法骨架；
  5. 点 main 左侧绿色三角运行，底部 Run 窗口出现输出即成功。
public class Hello {
    public static void main(String[] args) {
        System.out.println("环境搭建成功！");
    }
}
推荐设置：Settings → Editor → Font 调大字号；Editor → General → Auto Import 勾选 Add unambiguous imports；Plugins 可装中文语言包。

2.5 JShell：不建项目先玩语法

JDK 9 起自带 JShell——交互式 REPL，输一行立刻出结果，适合验证小语法：

jshell
jshell> 1 + 2
$1 ==> 3
jshell> "abc".toUpperCase()
$2 ==> "ABC"
jshell> /exit

本书前几篇的语法片段都可以丢进 JShell 快速试。注意它会自动省略完整程序的仪式感（如 public 类、编译报错的严格性），正式代码仍要写进 IDEA 项目。

⚠ 常见坑清单

  • 坑 1路径含中文/空格：个别命令行工具处理路径会出错，JDK 与项目目录都用纯英文；
  • 坑 2多版本打架：装过多个 JDK 时，实际生效的由 PATH 顺序决定，不是"最新装的那个"；
  • 坑 3终端没重开：改完环境变量必须新开终端窗口，老窗口读的还是旧值；
  • 坑 4PowerShell 与 cmd 语法不同：cmd 用 echo %JAVA_HOME%，PowerShell 用 echo $env:JAVA_HOME，查资料注意区分；
  • 坑 5IDEA 找不到 JDK：New Project 的 SDK 下拉框为空时，点 Add SDK → JDK 手动选择安装目录。

环境问题 90% 出在 PATH 与 JAVA_HOME。排查口诀：先看命令能不能找到（PATH），再看找到的是不是你要的版本（顺序）。

本章习题

A 基础完成安装后，在终端记录三条验证命令的输出并存档——以后遇到"我明明装了"类问题时，这是第一证据。
B 进阶在 IDEA 新建项目写出 Hello 并运行成功；再用 JShell 计算 123456789 * 987654321，观察结果有没有"异常"。
C 挑战故意把 PATH 里的 %JAVA_HOME%\bin 删掉，重现"不是内部或外部命令"报错，再修复它——把排错过程内化成肌肉记忆。
