8.1 声明与三种初始化

// 1. 静态初始化：边声明边给值，长度自动确定
int[] scores = {90, 85, 77};
String[] names = new String[]{"张三", "李四"};

// 2. 动态初始化：先定长度，值用默认值填（int 为 0，引用为 null）
int[] arr = new int[5];
System.out.println(arr[0]);   // 0
String[] tags = new String[3];
System.out.println(tags[0]);  // null

// 3. 先声明后赋值
int[] data;
data = new int[]{1, 2, 3};    // 注意：new int[]{...} 不能省略类型
// data = {1, 2, 3};          // 编译错误！简写只能在声明时用
  • 数组长度创建后不可变——需要变长用 ArrayList（第 24 章）；
  • 推荐写法 int[] arr 而不是 int arr[]（C 风格遗留）；
  • 创建长度为 0 的数组 new int[0] 合法且有用（表示"无结果"而非 null）。

8.2 访问、length 与边界

int[] arr = {10, 20, 30, 40};

arr[0] = 99;                    // 读写下标从 0 开始
System.out.println(arr.length); // 4 —— 是字段不是方法，无括号

// 遍历：普通 for（需要下标时）
for (int i = 0; i < arr.length; i++) {
    System.out.print(arr[i] + " ");
}

// 增强 for（只要值时）
for (int v : arr) {
    System.out.print(v + " ");
}

System.out.println(arr[4]);
// 运行时抛 ArrayIndexOutOfBoundsException——最大合法下标是 length-1
常见坑数组下标越界是运行时错误，编译器不报。永远记住合法范围 [0, length-1]；遍历条件写 < length 而不是 <= length。

8.3 数组是引用类型：别名问题

int[] a = {1, 2, 3};
int[] b = a;          // b 和 a 指向同一个数组对象！
b[0] = 100;
System.out.println(a[0]);   // 100 —— a 也"变"了

int[] c = a.clone();        // 真正复制一份新数组
c[0] = 7;
System.out.println(a[0]);   // 100 —— 不受影响

赋值复制的是引用（地址），不是数组内容。想要独立副本，用 clone()、Arrays.copyOf 或 System.arraycopy。

结合第 7 章的值传递：把数组传给方法，方法里改元素外面看得见，方法里 arr = new int[...] 外面看不见——原理完全相同。

8.4 多维数组

// 二维数组：本质是"数组的数组"
int[][] grid = {
    {1, 2, 3},
    {4, 5, 6},
    {7, 8, 9}
};
System.out.println(grid[1][2]);    // 6（第 2 行第 3 列）
System.out.println(grid.length);   // 3（行数）
System.out.println(grid[0].length);// 3（第 1 行的列数）

// 不规则数组：每行长度可以不同
int[][] tri = new int[3][];
tri[0] = new int[1];
tri[1] = new int[2];
tri[2] = new int[3];

// 双层遍历
for (int i = 0; i < grid.length; i++) {
    for (int j = 0; j < grid[i].length; j++) {
        System.out.print(grid[i][j] + " ");
    }
    System.out.println();
}
Java 没有"真正的二维数组"，只有嵌套的一维数组——所以才有不规则数组，也才需要 grid[i].length 这种逐行取长度的写法。

8.5 Arrays 工具类

import java.util.Arrays;

int[] arr = {5, 2, 8, 1};

System.out.println(Arrays.toString(arr));   // [5, 2, 8, 1]（直接打印数组只会得到地址！）

Arrays.sort(arr);                           // 原地排序 [1, 2, 5, 8]
int idx = Arrays.binarySearch(arr, 5);      // 二分查找（必须先有序）
int[] copy = Arrays.copyOf(arr, 6);         // 复制并扩到 6 位，补 0
Arrays.fill(copy, 5, 6, 99);                // 区间填充

System.out.println(Arrays.equals(arr, copy)); // 逐元素比较，不是 ==
  • Arrays.toString() 是打印数组唯一正确姿势——直接 System.out.println(arr) 输出的是 [I@1b6d3586 这种地址形式；
  • binarySearch 前提是数组已排序，否则结果不可信；
  • equals 比较内容；== 比较引用——又是第 8.3 节那条规则。

✓ 本章小结

要点一句话
初始化静态 {}、动态 new 定长、声明后赋值必须 new int[]{...}
边界合法下标 [0, length-1]，越界是运行时异常
引用语义赋值/传参共享同一数组；复制用 clone/copyOf
多维数组的数组；支持不规则；逐行取 length
ArraystoString 打印、sort 排序、binarySearch 查找、equals 比较
