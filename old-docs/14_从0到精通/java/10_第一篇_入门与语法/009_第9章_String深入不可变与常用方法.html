9.1 String 的两层身份与不可变性

String 有两层身份：它是一个类（引用类型），同时因为太常用，Java 给了它字面量语法和运算符特权：

String s1 = "hello";              // 字面量：进字符串常量池
String s2 = new String("hello");  // new：一定在堆里新建对象
String s3 = "hel" + "lo";         // 编译期常量折叠 → "hello"，进池

不可变（immutable）

String s = "hello";
s.toUpperCase();            // 返回新对象 "HELLO"，s 不变！
System.out.println(s);      // hello
s = s.toUpperCase();        // 必须接住返回值
System.out.println(s);      // HELLO

String 内部的字符数组用 final 修饰且不提供修改入口，任何"修改"都返回新对象。这样设计的原因：

  • 安全：文件路径、数据库连接串、类名等广泛使用字符串，不可变防止被暗中篡改；
  • 常量池复用：相同的字面量全局只存一份，省内存；
  • 线程安全：不可变对象天生可并发共享，无需加锁（第 57 章的"不可变模式"）。
牢记：String 的所有"修改类"方法（replace/trim/toUpperCase/concat…）都返回新串，原串永远不变。忘记接返回值是新手第一大错。

9.2 比较字符串：== 的陷阱

String a = "hello";
String b = "hello";
String c = new String("hello");

System.out.println(a == b);        // true —— 同一个常量池对象
System.out.println(a == c);        // false —— new 出来的是另一个对象
System.out.println(a.equals(c));   // true —— 内容相同

String d = "hel";
String e = d + "lo";               // 运行期拼接 → 新堆对象
System.out.println(a == e);        // false！
System.out.println(a == e.intern()); // true —— intern 归池后相同
  • == 比较的是地址；equals() 比较的是内容（String 已重写 equals，第 20 章详讲）；
  • 字面量相同会共享常量池对象，所以 == 有时"碰巧"为 true——这恰恰是最危险的误导；
  • 结论：比较字符串内容永远用 equals，无一例外。
常见坑变量在前更防空指针：已知常量放前面 "admin".equals(input)，input 为 null 时返回 false 而不是抛异常。

9.3 常用方法速查

String s = "Hello,Java,World";

s.length();                 // 16 —— 长度是方法，与数组的 length 字段区分
s.charAt(0);                // 'H'
s.indexOf("Java");          // 6（找不到返回 -1）
s.substring(6);             // "Java,World"
s.substring(6, 10);         // "Java"（含头不含尾）
s.split(",");               // ["Hello", "Java", "World"]
s.replace("Java", "C++");   // "Hello,C++,World"（新对象）
s.toLowerCase();            // "hello,java,world"
s.trim();                   // 去两端空白（strip() 更全面，Java 11+）
s.contains("Java");         // true
s.startsWith("Hello");      // true
String.join("-", "a", "b"); // "a-b"
String.valueOf(123);        // "123" 任意类型转字符串
"abc".compareTo("abd");     // 负数：字典序比较

三个高频细节：

  • substring(begin, end) 含头不含尾，与循环边界约定一致；
  • split 参数是正则表达式：按点号切分要写 split("\\.")，按竖线要 split("\\|")；
  • isEmpty() 只判断长度 0；判空白用 isBlank()（Java 11+）。

9.4 拼接性能与 StringBuilder

// 反面教材：循环里用 + 拼接
String bad = "";
for (int i = 0; i < 100000; i++) {
    bad += i;      // 每轮都新建对象+复制，O(n²) 灾难
}

// 正确姿势：StringBuilder（非线程安全，最快）
StringBuilder sb = new StringBuilder();
for (int i = 0; i < 100000; i++) {
    sb.append(i);
}
String good = sb.toString();

// 多线程共享拼接才用 StringBuffer（加锁，较慢）

原理一句话：String 不可变，+ 每次拼接都会创建新对象并复制全部字符；StringBuilder 内部维护可扩容的字符数组，追加是摊还 O(1)。

单行 "a" + x + "b" 的拼接，编译器会自动优化成 StringBuilder，不必手写。需要手动管理的是循环内的拼接。StringBuilder 的两个高频方法：append 与 reverse（回文判断利器）。

选型口诀：单次拼接随便写；循环拼接 StringBuilder；多线程共享 StringBuffer；大量格式化看 String.formatted / MessageFormat。

✓ 本章小结

要点一句话
不可变所有"修改"返回新串，原串不变；必须接住返回值
常量池字面量共享池对象；new 一定新建堆对象
比较内容比较永远用 equals；常量放 equals 前面防空
split 细节参数是正则；. 与 | 要转义；substring 含头不含尾
