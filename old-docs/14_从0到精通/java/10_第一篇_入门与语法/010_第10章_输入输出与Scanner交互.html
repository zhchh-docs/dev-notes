10.1 标准输出 System.out

程序默认有三根"管子"：标准输入 System.in、标准输出 System.out、标准错误 System.err。控制台里你看到的打印，都从 System.out 这根管子流出。

输出有三个常用方法，区别只在"换不换行"和"格不格式化"：

System.out.print("不换行");     // 打印后光标停在同一行
System.out.print("继续");

System.out.println("自带换行");  // 打印完追加一个换行符
System.out.println();           // 什么都不打，只换行

System.out.printf("姓名=%s 年龄=%d%n", "张三", 18);  // 格式化输出，%n 是平台换行符
  • print 不换行，适合拼着打印；
  • println 最常用，打印完自动换行；
  • printf 按"占位符模板"输出，下一节专门讲。
常见坑别用 \n 和 %n 混为一谈：\n 是固定换行符，在 Windows 上可能显示异常；%n 是 printf 里的"平台无关换行符"，跨平台更安全。

10.2 Scanner 读取控制台输入

控制台程序要"听懂用户说话"，最省事的方式是 Scanner：把它包在 System.in 外面，就能用一堆 nextXxx 方法方便地把键盘输入解析成各种类型。

import java.util.Scanner;

public class InputDemo {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);   // 把标准输入交给 Scanner

        System.out.print("请输入年龄：");
        int age = sc.nextInt();                // 读一个整数
        System.out.print("请输入姓名：");
        String name = sc.next();               // 读一个"单词"（到空格为止）
        System.out.print("请输入身高：");
        double height = sc.nextDouble();       // 读一个小数

        System.out.println(name + "，" + age + "岁，身高" + height + "米");
        sc.close();                            // 用完关闭，释放资源
    }
}
  • nextInt() 读整数，nextDouble() 读小数，next() 读一个以空白分隔的单词；
  • nextLine() 读一整行（直到回车）；
  • 养成习惯：不再用就 close()，避免资源泄漏。

10.3 next 与 nextLine 的换行大坑

这是初学者在控制台交互里踩得最狠的一个坑。先看会出问题的代码：

Scanner sc = new Scanner(System.in);
System.out.print("年龄：");
int age = sc.nextInt();          // 用户输入 18 并回车
System.out.print("姓名：");
String name = sc.nextLine();     // 期望读名字，却直接"跳过"了！

System.out.println("年龄=" + age + " 姓名=[" + name + "]");
// 姓名是空字符串，程序根本没等你输入

为什么会这样？

nextInt() 只读走了数字 18，把回车产生的换行符 \n 留在了缓冲区。紧接着的 nextLine() 一上来就看到这个换行符，立刻把它当作"一行结束"消费掉，于是读到一个空串，自然就"跳过"了。

记住一句话：nextInt / nextDouble / next 只读取内容、不消耗换行符；nextLine 专门吃换行符。两者混用，必须先清掉残留的换行。

两种正确写法

// 写法一：在 nextInt 之后补一个 nextLine 把换行"吃掉"
int age = sc.nextInt();
sc.nextLine();                 // 消耗掉残留的换行符
String name = sc.nextLine();  // 这次能正常读

// 写法二（更推荐）：全程用 nextLine 读字符串，再自己解析
int age = Integer.parseInt(sc.nextLine());
String name = sc.nextLine();
常见坑如果你"先 nextLine 后 nextInt"则没有这个坑，因为 nextLine 已经把整行（含换行）吃干净了。坑只发生在"数值/单词方法在前、nextLine 在后"的顺序上。

10.4 hasNext 校验与循环读入

用户输入什么都可能：字母当数字、空行、文件结束。用 hasNextXxx() 先探一下"下一个是不是想要的类型"，能写出健壮的输入循环。

Scanner sc = new Scanner(System.in);
int sum = 0;
System.out.println("请输入若干整数，输入非数字结束：");
while (sc.hasNextInt()) {           // 下一个还是整数才继续
    sum += sc.nextInt();
}
System.out.println("总和=" + sum);

带校验的"请重输"循环

实战里常要求"必须输入合法值，否则反复提示"：

Scanner sc = new Scanner(System.in);
int age = -1;
while (true) {
    System.out.print("请输入合法年龄(0-150)：");
    if (sc.hasNextInt()) {
        age = sc.nextInt();
        if (age >= 0 && age <= 150) {
            break;                  // 合法，跳出循环
        }
        System.out.println("范围不对，请重输。");
    } else {
        System.out.println("那不是数字，请重输。");
        sc.next();                  // 关键：丢掉这个非法 token，否则死循环
    }
}
System.out.println("你输入的年龄是 " + age);
常见坑当 hasNextInt() 为 false 时，必须调用一次 next() 把那个非法输入从缓冲区清掉，否则下一次循环它还在，程序会无限打印提示——典型的"卡死"现场。

10.5 printf 格式化输出

想让输出对齐、保留小数位、补零，printf 比字符串拼接优雅得多。它用占位符描述格式，后面按顺序填值。

String name = "张三";
int age = 18;
double salary = 12345.6789;

System.out.printf("姓名：%s，年龄：%d%n", name, age);
System.out.printf("工资：%.2f%n", salary);          // 保留两位小数 → 12345.68
System.out.printf("编号：%05d%n", 42);             // 补零到5位 → 00042
System.out.printf("左对齐：|%-10s|%n", "hi");      // 占10位左对齐
System.out.printf("百分比：%.1f%%%n", 0.123);      // 0.1%（%% 才是一个 %）
占位符含义
%s字符串
%d十进制整数
%f浮点数，%.2f 保留两位
%n平台无关换行符
%%输出一个百分号本身
%05d / %-10s补零定宽 / 左对齐定宽
格式化三件套：%.2f 控精度、%0Nd 补零、%-Nx 左对齐，报表和日志输出天天用。

10.6 BufferedReader 备选方案

Scanner 方便但解析较慢，且按空白分词不适合读"含空格的一整行"。在需要高性能或读取整行文本时，老牌的 BufferedReader 更合适：

import java.io.BufferedReader;
import java.io.InputStreamReader;
import java.io.IOException;

public class BrDemo {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(
                new InputStreamReader(System.in));   // 字节流→字符流→带缓冲
        System.out.print("请输入一行（可含空格）：");
        String line = br.readLine();                 // 读整行，含空格也完整
        System.out.println("你输入了：" + line);
        br.close();
    }
}
  • readLine() 直接拿到含空格的完整一行，没有 Scanner 的分词困扰；
  • 读到文件末尾返回 null；方法声明抛 IOException，需 throws 或 try-catch；
  • 若要数字，仍需 Integer.parseInt(line) 等自行转换。
常见坑初学者常把 System.in 直接当字符流用——不行，它是字节流，必须先用 InputStreamReader 桥接成字符流，否则中文会乱码。这条转换链 BufferedReader → InputStreamReader → System.in 要记牢。
