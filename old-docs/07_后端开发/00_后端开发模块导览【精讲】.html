技术栈详解 · 07_后端开发

后端开发 · 模块导览

精讲 本模块 10+1 篇 · 建议学习时长 3~4 周

这是前端转全栈的核心跨越。本模块以 Java/Spring 为主线：先语言（Java 基础/并发/JVM），再容器（Tomcat），然后 Spring 体系（核心→Boot→MyBatis），最后是接口层三件套（RESTful/Swagger/JWT）。SSH 作为遗产框架压轴——维护老系统时你会遇到它。

1这个模块解决什么问题

读完本模块，你应该能：独立设计并实现一套带鉴权、符合 RESTful 规范、有接口文档的后端服务，并与前端联调闭环。

  • 给转全栈的你：语言直觉的差异（静态类型、编译期、线程模型）是第一道坎，01-02 专门解决它。
  • 给面试的你：IoC/AOP 原理、Bean 生命周期、MyBatis 缓存、JWT 无状态利弊是高频区。
  • 给联调的你：RESTful 设计 + Swagger 契约 + JWT 鉴权，是前后端协作的三份"合同"。

2知识地图与学习顺序

本模块 10 篇按学习曲线排列，编号即建议阅读顺序。每篇标注了前置依赖，跳读前请确认前置已过。

篇目为什么排在这个位置前置
101_Java基础【标准】语言与面向对象：类型系统、集合、异常、泛型01 模块
202_Java并发与JVM【标准】内存模型、线程池、JVM 分区与 GC——与 01 模块 JS 的单线程模型对照着学1
303_Tomcat与Jetty服务器【基础】Servlet 容器：请求如何从端口到你的代码1
404_Spring核心_IOC与AOP【深入】IoC 容器与 AOP：控制反转解决什么、代理怎么织入1
505_SpringBoot框架【标准】工程骨架：自动配置、起步依赖、配置体系4
606_MyBatis持久层【深入】持久层：SQL 映射、动态 SQL、缓存——配合 08 模块 01 的 SQL 能力5、08 模块
707_RESTful_API设计【标准】接口设计规范：资源、方法、状态码、版本化5
808_Swagger与OpenAPI接口契约【标准】接口契约：文档即代码，契约先行7
909_接口安全_JWT与鉴权【标准】认证授权：JWT 结构、无状态利弊、RBAC5、01 模块 5
1010_SSH框架【基础】遗产框架（Struts2/Hibernate）——老系统维护专用4

顺序设计原则：语言（1-2）先于容器（3）与框架（4-6）——Spring 的依赖注入需要先懂面向对象与反射；接口层（7-9）依赖 Boot 工程存在；SSH 放最后，只作为遗产阅读。

4模块边界：这里不讲什么

  • 数据库与 SQL 本身在 08 模块（本模块只讲持久层框架）；
  • 微服务与网关（SpringCloud）未收录，属进阶方向；
  • 消息队列、缓存中间件在 12 路线图阶段；
  • 前端如何调这些接口在 01 模块 5（HTTP）。
