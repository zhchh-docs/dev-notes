1这个模块解决什么问题

框架与工程化会不断更新，但本模块的内容十年不变：页面结构与样式、语言运行模型、浏览器工作原理、通信协议。它决定你排查问题的深度——框架层查不出的问题，最终都要回到这里。

  • 给转全栈的你：后端联调要求你懂 HTTP 与浏览器网络行为；性能问题要求你懂渲染管线；安全事故要求你懂浏览器信任模型——这些全在本模块。
  • 给面试的你：前端基础是所有面试的第一关，本模块的【深入】三篇（HTML/CSS、JS 核心、JS 异步）覆盖 80% 的基础题。
  • 给后续模块的你：框架篇的响应式原理 = JS 核心；工程化的打包优化 = 浏览器渲染 + HTTP 缓存；全栈的后端联调 = HTTP 与安全。

2知识地图与学习顺序

本模块 10 篇按地基 → 语言 → 环境 → 通信 → 进阶方向排列，编号即建议阅读顺序。每篇标注了前置依赖，跳读前请确认前置已过。

篇目为什么排在这个位置前置
1HTML5与CSS3【深入】表达层地基：页面结构与样式的组织方式，后续一切视觉与交互的载体无
2JavaScript核心【深入】语言运行模型：类型、作用域、闭包、this、原型链、GC——本模块最重要的一篇1
3JS进阶：事件循环与异步【深入】单线程下的并发模型： Promise/async、宏微任务——框架与 Node 共用的心智模型2
4浏览器原理与渲染机制【标准】代码与像素之间发生了什么：解析、渲染管线、重排重绘——性能优化的理论根基1、2
5HTTP与跨域请求【标准】前后端通信的协议层：方法、状态码、缓存、Cookie、CORS——联调与全栈必备4
6TypeScript【深入】给 2 的动态类型加编译期保险：现代团队标配，转型全栈的代码质量门槛2
7响应式布局：Flex与Grid【标准】现代布局两把刀：与 1 的 CSS 基础配合，解决一切排版需求1
8Tailwind CSS 原子化【标准】样式工程化：原子类的组织思想，与 7 的底层能力互补1、7
9前端安全：XSS与CSRF【基础】浏览器信任模型的攻击面与防御——联调后端接口前必须建立的安全意识2、5
10Canvas与SVG【深入】分支方向：像素级与矢量级绘图，通往数据可视化模块（03）的桥2

顺序设计的两条原则：①语言（2、3）先于环境（4、5），因为渲染与网络问题的解释都依赖语言模型；②安全（9）排在 HTTP（5）之后，因为 CSRF/CORS 的理解依赖协议层。Canvas/SVG 放最后——它是通往可视化方向的分支，不是主线路径。

4模块边界：这里不讲什么

  • 不讲框架：Vue/React 在 02 模块，本模块给的是框架脚下的地基；
  • 不讲工程化：Vite/Webpack/测试在 06 模块，本模块只涉及它们的原理依据（渲染、HTTP 缓存）；
  • 不讲可视化深入内容：Canvas/SVG 本篇只讲绘图模型，ECharts/D3/Three.js 在 03 模块；
  • 不讲 Node：本模块的 JS 概念在 Node 通用，但服务端 API 在 12 路线图的「Node 后端」阶段。
