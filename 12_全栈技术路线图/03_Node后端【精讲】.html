3.1Node 是什么

Node 不是一门语言，是让 JavaScript 跑在服务器上的运行时。它 = V8 引擎（执行 JS 代码）+ libuv（提供事件循环、异步 IO）+ 内置模块（fs/http/path…）。

💡 单线程 + 事件循环：Node 不做多线程，而是用一个主线程配合 IO 多路复用处理几万并发连接。CPU 密集型任务会卡住事件循环，所以 Node 适合 IO 密集（接口、实时推送），不适合计算密集（视频转码）。

3.3Stream 流与背压

读一个 2GB 文件如果一次性读进内存会炸内存。Stream 把数据切成一小块一小块传，边读边处理。

类型方向例子
可读流 Readable读出来fs.createReadStream、HTTP 请求体
可写流 Writable写进去fs.createWriteStream、HTTP 响应
双工流 Duplex既能读又能写Socket
转换流 Transform边读边改gzip 压缩
⚠️ 背压（Backpressure）：如果读得快、写得慢，数据会堆在内存里。解决：用 pipeline() 自动处理背压，不要手动 data 事件写死循环。

3.4Koa 洋葱模型

Koa 的中间件是洋葱圈：请求进来一层层穿过中间件，到达最内层后，再一层层出去。

app.use(async (ctx, next) => {
  const start = Date.now();
  await next();               // ← 等里面所有中间件跑完
  console.log('耗时', Date.now() - start, 'ms');
});
app.use(async (ctx, next) => {
  // 鉴权
  await next();
});
💡 await next() 是关键：它把控制权交给下一个中间件，等它全部跑完（包括更内层），再回来执行后面的代码。这就是"洋葱"——进去和出来都能插逻辑。

3.5NestJS 概览

NestJS 是 Node 版的 Spring，用 TypeScript 写，核心概念：

概念作用类比 Spring
Module 模块组织代码，导入导出@Configuration
Controller处理 HTTP 请求@RestController
Provider / Service业务逻辑，可注入@Service
依赖注入 DI构造函数声明，框架自动传实例@Autowired
Guard 守卫鉴权（路由能不能进）拦截器
Pipe 管道参数校验、转换参数解析
Interceptor 拦截器前后置处理（日志、响应包装）AOP 环绕通知
ExceptionFilter统一异常处理@ControllerAdvice

3.6RESTful API 设计

把后端数据当成"资源"，用 URL 表示资源，用 HTTP 方法表示操作：

操作URL方法说明
用户列表/api/usersGET查全部
单个用户/api/users/123GET查详情
新建用户/api/usersPOST创建
更新用户/api/users/123PUT/PATCH更新
删除用户/api/users/123DELETE删除

统一响应格式

{
  "code": 0,          // 0 成功，非 0 业务错误码
  "message": "ok",
  "data": { ... }     // 真正的数据
}
💡 幂等性：GET/PUT/DELETE 天然幂等（调多次结果一样），POST 不幂等（调多次创建多条）。重要的写操作前端要带唯一请求 ID 防止重复提交。

3.7JWT 鉴权

登录成功后服务器发一个 Token，前端每次请求带上，服务器验签即可，不用存 Session。

⚠️ JWT 的坑：① Payload 是 base64 编码不是加密，不能放密码等敏感信息；② Token 签发后服务器没法主动作废，只能等过期，所以 accessToken 要短命，refreshToken 用来换新。

3.8限流算法

算法原理优缺点
固定窗口每分钟允许 100 次简单，但窗口边界会突刺（59s 100 次 + 01s 100 次，瞬间 200）
滑动窗口窗口随时间滑动统计平滑，缺点是要存历史记录
漏桶水（请求）进桶，恒定速率漏出输出绝对平滑，但没法应对突发
令牌桶桶以固定速率放令牌，请求拿到令牌才放行最常用：允许一定突发（桶里有令牌就能冲）
💡 实际项目：单机限流用 express-rate-limit，分布式限流用 Redis + Lua 脚本保证原子性。

3.9PM2 进程管理

Node 单进程挂了服务就断。PM2 帮你做：后台常驻、崩溃自动重启、多进程利用多核、日志收集。

pm2 start app.js -i 4   # 启动4个进程集群模式
pm2 list                # 查看状态
pm2 logs                # 看日志
pm2 restart app         # 重启
