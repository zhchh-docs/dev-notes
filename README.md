## 📚 知识库概览

本知识库覆盖全栈开发核心技术栈，共 **113 篇技术详解文章**，分为 **12 大模块**。每篇文章均为自包含 HTML：浏览器直接打开即可阅读，图示全部为内联 SVG（离线可看、不依赖外部库），无构建、无安装。

### 深度分级

| 标签 | 含义 | 内容深度 |
|------|------|---------|
| **【深入】** | 熟练掌握 | 原理 + 流程 + 源码级 + 实战要点 |
| **【标准】** | 熟悉 | 概念 + 核心要点 + 常用用法 |
| **【基础】** | 了解 | 是什么 + 能做什么 + 入门要点 |

## ✨ 特色

### 📝 每篇文章结构统一
1. **技术点概览** — 是什么、解决什么问题，配定位图
2. **核心概念** — 分条实质讲解
3. **工作原理/流程** — 流程图/架构图/时序图（内联 SVG）
4. **核心语法/API** — 常用代码片段
5. **实战要点** — 常见问题与解决方案
6. **易错点/面试重点** — 高频考点与踩坑总结

### 📊 全面学习系列
「全面学习」模块为体系化精讲，共 7 篇，目标是把全栈各领域的知识点按「基础 → 标准 → 深入」三层囊括完整，每篇配代码示例和流程图，适合快速建立知识体系：
- 知识体系总纲 — 12 大领域 × 三层知识点总清单 + 学习路径 + 覆盖进度
- 前端基础篇 — HTML/CSS/JS/TS/HTTP 核心概念（36 个知识点）
- 前端框架篇 — Vue/React/状态管理/微前端
- 前端工程化篇 — 构建/Git/规范/性能优化
- 后端开发篇 — Java/Spring/MyBatis/接口安全
- 数据与运维篇 — MySQL/Redis/Docker/CI-CD
- 软技能与AI篇 — 设计原则/调试/AI编程/团队协作

### 🔍 术语系统
全站内置术语解释系统，正文中出现的技术术语可点击查看详细解释，底部术语表汇总全部术语。

## 🚀 本地使用

1. 克隆仓库：
```bash
git clone https://github.com/zhchh-create/zhchh-docx.git
```

2. 直接用浏览器打开 `index.html` 即可浏览全部内容。

无需安装任何依赖、无需构建，纯静态文件，断网也可正常阅读。
