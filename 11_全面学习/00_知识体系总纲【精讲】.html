1总纲说明

本篇是「全面学习」系列的路线总图：把全栈开发与计算机科学涉及的12 大领域，按基础 → 标准 → 深入三个层次列出全部知识点，标记每个知识点的覆盖状态，并给出循序渐进的学习路径。

三个层次的定义（与全库深度分级一致）：

  • 基础 是什么 + 能做什么 + 入门要点 — 先搞懂，能上手
  • 标准 概念 + 核心要点 + 常用用法 — 日常开发的主力
  • 深入 原理 + 流程 + 源码级 + 实战要点 — 排查问题与进阶

覆盖状态标记：✅ 已覆盖 知识点已写入对应精讲篇；🔶 待扩充 篇目已存在、知识点待补充；🆕 新增篇目 需要新建独立精讲篇。

💡 使用方式：对照「知识点总清单」检查自己缺什么 → 按「学习路径」的先后顺序 → 进入对应精讲篇逐层消化 → 需要细节时跳转全库详细文章。

3知识点总清单

以下按领域列出全部知识点，每个知识点标注层次与覆盖状态。清单是「囊括各领域所有知识点」的核对表，也是后续扩充工作的施工图。

A · 计算机基础 ✅ 已覆盖：07_计算机基础篇

操作系统的进程内存、计算机网络的协议分层、计算机组成原理，是所有上层技术的地基。

层级知识点
基础二进制与位运算；数据单位与字符编码（ASCII / UTF-8）；CPU 与内存的基本模型；冯·诺依曼结构；操作系统的基本概念（进程 / 线程 / 文件）
标准进程与线程模型；进程间通信（管道 / 消息队列 / 共享内存 / 信号量）；虚拟内存与分页；死锁的四个必要条件与预防；TCP/IP 四层模型与 OSI 七层模型；IP 地址、端口与 DNS 解析；HTTP 请求模型；常用网络命令（ping / netstat / curl）
深入线程同步（互斥锁 / 自旋锁 / 信号量）；并发模型对比（多线程 / 协程 / 异步）；TCP 三次握手与四次挥手、拥塞控制；TLS/HTTPS 握手过程；缓存一致性（MESI 简述）；零拷贝技术；CPU 调度算法与性能分析（CPU / 内存 / IO）

B · 数据结构与算法 ✅ 已覆盖：08_数据结构与算法篇

写代码的底层能力，也是面试考察的重点。掌握常用数据结构与算法思维，才能真正评估方案复杂度。

层级知识点
基础数组与链表；栈与队列；哈希表（Hash 冲突与解决）；字符串常用操作；时间复杂度与空间复杂度（大 O 记号）
标准二叉树遍历（前序 / 中序 / 后序 / 层序）；二叉搜索树；堆与优先队列；图的基础（邻接表 / BFS / DFS）；排序算法（冒泡 / 快排 / 归并 / 堆排 / 插入）；二分查找；递归与分治
深入动态规划（背包 / 最长递增子序列 / 编辑距离）；贪心算法与适用条件；回溯算法（排列组合 / N 皇后）；并查集；Trie 字典树；LRU 缓存实现；红黑树与 AVL 树简述；高频手写题（反转链表 / 两数之和 / 无重复最长子串）；算法思维（双指针 / 滑动窗口 / 前缀和）

HTML/CSS/JavaScript/TypeScript 与浏览器原理，一切前端能力的基础。

层级知识点
基础HTML 文档结构与基本标签；语义化标签；表格与表单；CSS 选择器与优先级；CSS 盒模型；CSS 常用属性；JS 变量与数据类型；JS 运算符与类型转换；JS 流程控制；JS 函数；浏览器开发者工具
标准Flexbox 弹性布局；Grid 网格布局；定位与层级（position / z-index）；响应式布局与媒体查询；DOM 操作与事件绑定；事件冒泡与事件委托；Fetch 网络请求；本地存储（Cookie / localStorage / IndexedDB）；数组与对象常用方法；ES6+ 常用语法；TypeScript 类型基础；表单处理与校验、正则表达式
深入作用域与作用域链；闭包；this 指向与 call/apply/bind；原型链与继承；事件循环与异步原理；深拷贝与浅拷贝；防抖与节流；浏览器渲染原理（回流 / 重绘）；浏览器缓存机制；HTTP 协议与状态码；同源策略与跨域（CORS）；前端安全（XSS / CSRF）；Canvas 与 SVG

6使用方法

  • 查缺补漏：对照「知识点总清单」，逐项自评「会 / 不会」，不会的进入对应精讲篇。
  • 逐层学习：每个领域先扫基础层（半天内），再做标准层（动手写代码），最后攻深入层（结合 bug 与面试题）。
  • 跳转细节：精讲篇是「地图」，全库 01~10 模块的详细文章是「街区」——精讲篇每个知识点的「深入阅读」链接可直接跳转。
  • 术语联动：正文中的技术术语可点击查看全站术语表解释。
